# 变量自动编码器

变化自动码器 (VAE) 转换了基本的自动码器 (见 [unsupervised-learning.md](../02-classical-ml/unsupervised-learning.md),这种模型可以产生新的,现实的样本,而不仅仅是压缩和重建现有的样本.[diffusion-models.md](diffusion-models.md)).

## 从自动编码器到生成模型

**简单的自动编码器的问题.**基本的自动编码器 (见[unsupervised-learning.md](../02-classical-ml/unsupervised-learning.md)) 学习将输入映射到隐藏空间中的点 (压缩向量表示) 和回路,但它没有提供任何保证*什么是什么*它们可能是分散的,不连接的方式,使得大小的"空隙"没有意义.如果你试图通过选择一个随机的点在隐藏空间中并解码来生成一个新例子,你就无法知道这个点是否落地在某个地方.解码器实际上知道如何转化为现实.

**概念上,这是一个解决方案.**AAE强迫隐藏空间具有特定的,行为良好的整体形状,它鼓励编码器将输入映射到分布在标准正常 (高斯) 分布的点上,而不是任意的,不受限制的点上.如果整个隐藏空间以这种方式形成,则随机从标准正常分布中抽样并将样本输入到解码器中应该可靠地产生一些现实的输入.

**起源.**基因,威林, "自动编码变量贝尔" (2013/2014).

## 修复尺寸的技巧

**它解决了问题.**训练需要通过整个编码器-解码器管道 (见 [optimization-algorithms.md](../01-foundations/optimization-algorithms.md),你不能直接问"如果μ稍微变化,损失会如何变化",因为*随机性*它们本身位于μ/σ和z之间,阻止梯度以正常的方式流动.

**子.**取代于直接从N ((μ, σ2) 采样z,采样一个固定的辅助随机值 ε ~N(0,1) (标准正常,没有学习参数) 并从 μ, σ, ε 计算z 确定性:

```
z = μ + σ · ε
```

通过:这与采样等于数学上~直接 (乘以 σ 的标准正常样本,并将其转移到 μ 的样本,就产生了正确的 N μ, σ 2 分布值),但它重组计算,使所有*随机性*由于z现在是 μ, σ,和 ε 的确定性,可分化函数,因此梯度可以通过z 往 μ 和 σ 流向后 (从那里,回到编码器的权重) 正如通过任何其他层一样.这是一个真正聪明的,不显而易见的工程.

下面的图表显示了为什么它很重要"随机"步骤与梯度路径相对位置:

```
   WITHOUT the trick (can't train):        WITH the trick (trainable):

   x → encoder → (μ, σ) → [sample z] → decoder → x̂     x → encoder → (μ,σ) ─┐
                              ▲                                               ├─→ z = μ+σ·ε → decoder → x̂
                     random step BLOCKS                    ε ~ N(0,1) ───────┘         │
                     the gradient from                    (random, but OUTSIDE         │
                     reaching μ, σ                          the gradient path)   gradient flows
                                                                                 back through μ,σ ✓
```

梯度需要从损失中重新进行可分化的持续跟踪,直到每一个学习的参数. 一个原始的"绘制随机样本"操作是梯度无法穿过的墙壁.通过重写样本为`μ + σ·ε`随着 ε 来自外部,梯度的路径上的唯一东西是普通的算数 (乘以,加) 随机性被转移到梯度不需要去的地方.

## 在公式前解释的ELBO

**首先用简单的英语.**理想情况下,一个VAE希望直接最大化训练数据的概率,在模型下大致",我的模型认为真正的训练例子是多可能的" (更高是更好).但计算这个精确的概率需要考虑每一个可能的隐藏向量z,可能会产生给定的输入x,这通常是难以解决的 (对于一个复杂模型来说,没有有效的方法来总和/整合它们).相反,VAE最大化一个*下边界*总是比真实 (不可处理) 的可能性小或等于,但实际上可以计算的数量.这个底界称为**证据下层结合**其他**鱼类**逻辑是:因为你不能直接最大化真正的目标,而是最大化最好的可计算的替代,因为它是真正的下边界 (而不是只是一个松散的近似),

**公式.**

```
ELBO = 𝔼_{z~q(z|x)}[log p(x|z)]  −  D_KL(q(z|x) ‖ p(z))
```

每个术语的经历:|x) 是编码器在给给输入 x 的z 上分布 (从上面的 μ, σ); p(x|解码器分布在重建中,给出一个隐形的z; p(z) 是**之前** 良好的目标分布,我们希望隐藏空间看起来像总体 (标准正常,N(0,1))._现在,~|[记载|其他]现在,**复兴期限**模型的重建是通过编码器分布中抽取的隐藏样本进行的.[loss-functions.md](../01-foundations/loss-functions.md)) 在编码器分布 q(z之间| (x) 和前 (z) 是**规范化期限**训练最大化ELBO (同样,最小化其负值作为损失),这意味着平衡两个竞争压力:重建输入,但不要让潜伏分布离较好的,可样本的标准正常形状漂移太远.这种紧张正是给予训练的VAE既一个潜伏空间,足够有组织的样本,以及一个足够好的解码器,使这些样本看起来现实.

**典型的故障模式:后部崩.**如果解码器足够强大,可以重新构建输入,而大部分输入都会被解码器所控制.*忽视*模型可以将KL术语推到零,使编码输出基本上是每个输入的先进 (q(z|,所以z没有关于x的信息.ELBO看起来很好,但隐形代码已经"崩"到无用的,VAE已经然退化为一个无视其隐形输入的解码器.**后部崩**减轻 (KL缩逐步增加KL术语的权重;削弱解码器;或自由位技巧) 是实际的VAE工具包的标准部分.

** ()  ()  ()  ()**由于两个术语是紧张的,自然的必须按一个系数 β 权重 KL 术语:`reconstruction − β·KL`设置β > 1使隐藏的尺寸更加独立,每个尺寸都捕捉到不同的变化因子 (一种称为**解开**例如,一个隐形维度控制旋转,另一个控制尺寸),以一些成本重建敏度; β < 1 则反之. β-VAE (Higgins等人, 2017) 使此交易明确,是可控制隐形表示的标准参考点.

## 与自动编码器和扩散模型的关系

**对于普通的自动编码器.**简单的自动编码器 (见[unsupervised-learning.md](../02-classical-ml/unsupervised-learning.md)) 是确定性的 (固定输入 →固定隐藏点) 并没有鼓励一个有组织的隐藏空间的机制.它是一种压缩工具,而不是生成模型.

**对于扩散模型.**扩散模型 (见[diffusion-models.md](diffusion-models.md)) 可以在概念层面上看作是将VAE的核心思想推向极端:而不是一个编码步骤将输入压缩成一个隐形分布,扩散使用了许多小的,渐进的噪音步骤的长序列,而不是一个解码步骤,使用了许多小的指标步骤的长序列.[diffusion-models.md](diffusion-models.md)) 另外使用实际的VAE显然作为一个第一阶段压缩机在一个VAE的较小的隐藏空间中运行了散射过程,而不是直接在原始像素上,这是一种本文件所涵盖的VAE机制的直接,字面上的建筑重用,而不是仅仅是它的概念回声.

**分离的隐形,将其桥接到自动降低的生成.**一种VAE变体值得提及,因为它将此文件连接到[autoregressive-generation.md](autoregressive-generation.md) **型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型型**变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化,变化等.*离散*一:编码器输出将被切入学习的向量"代码书"中最接近的输入,因此每个隐藏位置实际上成为一个有限的词汇中的代码.为什么这很重要:一旦图像或音频剪辑被编码为一个格格/分离代码的序列,你可以用相同的自行降低,下一个代码预测机器进行模型,用于文本 (见[autoregressive-generation.md](autoregressive-generation.md)一个Transformer预测下一个图像代号. 这种"用VQ-VAE代号代号,然后自动生成代号"的配方是图像和音频生成系统 (包括神经音频代码和一些多模模型将图像视为代号序列的基础),也是VAE仍然与该领域的自动降低/LLM方面相关的主要原因,而不仅仅是扩散方面.

## 现状

**强度和局限性**
- 优势:有原则的概率框架,有组织良好的,可解释的,可以顺利插入的隐形空间;稳定,简单的训练 (与GAN的对抗游戏不同,一个单一的明确损失以最大限度地减少见[gans.md](gans.md));一旦训练,快速单通的发电.
- 限制:VAE生成的样本历史上往往看起来比GAN或扩散模型输出略模糊/不那么尖 (一个广泛观察到的,如果不是完全理论上定制的,经验趋势,通常归因于重建术语的行为在常用的简化假设下);在实践中,平衡重建和KL术语的良好调整可能需要仔细调整.

**现状.**作为一个*独立*通过扩散模型,截至截止的图像生成器在样品质量方面已经大幅超过了 (见[diffusion-models.md](diffusion-models.md)图像生成时代,由GAN (见[gans.md](gans.md)尽管如此,VAE机制本身仍然非常活跃,*组件*在现代系统中最突出,如隐藏的扩散架构中压缩阶段 (见[diffusion-models.md](diffusion-models.md)) 使得"自主发电机"和"目前的最新技术基础设施"同时"超越"VAE",这是值得精确的区别,而不是完全取消VAE.

## 较量表

|财产|简单的自动编码器|州|
|---|---|---|
|编码输出|单个确定性潜伏向量|隐形向量分布 (μ, σ) |
|隐形空间结构|没有保证好组织|为了一个平稳的,正常的形状.|
|能产生新的样本吗?|不是可靠的|是的,从前面的样本,解码|
|培训目标|只有重建损失|工业部 (重建+ KL规范化) |

## 与其他算法的关系

-  VAE是直接的概率扩展,[unsupervised-learning.md](../02-classical-ml/unsupervised-learning.md).
- 在ELBO中,KL分离术语是一般在[loss-functions.md](../01-foundations/loss-functions.md).
- 变化推理的"输入隐藏的结构,然后优化给出这个结构"的口味与 EM 算法相似[probabilistic-models.md](../02-classical-ml/probabilistic-models.md)虽然VAE通过梯度下降/后而不是EM的精确交替步骤进行优化.
- 隐形扩散模型中,VAE被用作一个字面上的建筑组成部分.[diffusion-models.md](diffusion-models.md).
