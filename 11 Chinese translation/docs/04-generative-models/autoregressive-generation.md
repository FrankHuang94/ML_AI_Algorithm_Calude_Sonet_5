# 逆转的世代

推迟生成是目前生产的基本上每一个大型语言模型背后的培训和样本化范式.该文件涵盖了下一个代码预测框架,在推理时使用的主要解码/样本化策略,为什么这种方法特别占据了文本生成的地位,以及随之而来的退化问题.

## 下一个词元预测框架

**名称和定义**一个自行降低模型一次生成一个序列的元素,每个新的元素都根据迄今为止生成的所有元素进行预测.

**核心机制.**对于文本来说,这意味着通过概率链规则,将整个词元序列的概率进行模型 (一个词元是文本的部分经常是一个单词或字体部分,语言模型将其视为单个单元)

```
p(x₁, x₂, ..., x_n) = p(x₁) · p(x₂|x₁) · p(x₃|x₁,x₂) · ... · p(x_n|x₁,...,x_{n-1})
```

通过:而不是试图一次地模拟整个序列的概率 (一个非常复杂的联合分布),这将问题分解成一个更简单的预测序列.[loss-functions.md](../01-foundations/loss-functions.md)它们是"单独的Transformer" (见 单独的Transformer).[transformer-architecture.md](../03-deep-learning-architectures/transformer-architecture.md)) 训练是这样做:给出词元前,输出一个概率分布 (通过软max在logits) 对于下一个词元,使用因果化伪装的自我注意,这样每个位置的预测只取决于在该位置或之前的词元.

**为什么这种训练目标如此强大?**每个培训文档中的每个词元同时提供了一个免费的培训示例 (预测这个词元从之前的一切) 没有需要手动标签,并且可直接使用大量的文本数据 (基本上全部).这是为什么仅使用解码器,自行降级训练的模型成为主导的LLM架构的训练侧面的一半.[transformer-architecture.md](../03-deep-learning-architectures/transformer-architecture.md)对于更完整的"为什么只有解码器赢得了"讨论,[pretraining-strategies.md](../05-training-methodology/pretraining-strategies.md)如何在实践中使用这一目标.

## 推理时采样策略

一旦一个模型能够在下一个词元上产生概率分布,就有选择如何从该分布中实际选择词元. 这是一个独立的决定,

战略最容易被视为不同的决策方式*概率分布的哪个部分是可接受的*假设模型在提示后"今天天气是"产生了下一个词元的分布:

```
   token:   "sunny" "warm" "cold" "nice" "mild" "rainy"  ... (thousands more, tiny probs)
   prob:     0.40    0.25   0.15   0.10   0.05   0.03     ...
            ████████ █████  ███    ██     █      ▌

   greedy      → takes only "sunny" (the single tallest bar). Deterministic.
   top-k=3     → eligible = {sunny, warm, cold}, then sample among those 3.
   top-p=0.80  → eligible = smallest set summing to ≥0.80 = {sunny, warm, cold} (0.40+0.25+0.15),
                 then sample among those. (If the distribution were flatter, top-p would
                 automatically include MORE tokens — that adaptivity is its whole advantage.)
   temperature → reshapes the bars BEFORE the above: T<1 makes tall bars taller
                 (more like greedy); T>1 flattens them (more surprising choices).
```

的取一个最高的条; 顶-k保持一个固定的数量的条; 顶-p (核) 保持多条是需要的覆盖一个固定的条.*概率质量*其他部分只是扩大了每个条的高度.

### 贪的解码

**机械.**每一步都选择最有可能的词元.

**交易.**确定性 (相同的输入总是产生相同的输出) 和简单,但容易产生重复性,通用文本,因为它只认为本地最佳的下一个词元可能会错过更好的整体序列,这可能需要一个本地稍微更糟糕的词元在一些早期的步骤 (在标准CS意义上是一个经典的贪算法限制).

### 射线搜索

**机械.**代替仅追踪单个最佳部分序列,在每个步骤中保持k最高概率的部分序列 ("束"),每一个词元扩大,并只保留总体最佳k结果序列,重复到完成.

**交易.**发现更高的可能性*总体*对于机器翻译等"正确"输出空间的任务,它仍然是标准的.对于开放式文本生成,光束搜索具有一个已证实的故障模式:它倾向于找到*,我也*由于模型的概率最高, 总的序列不一定是最有趣的或最像人类的.

### 温度

**机械.**在通过软max转换logits为概率之前,将logits分为温度值 τ:softmax(logits / τ). τ < 1 sharpens the distribution (makes the model more confident/deterministic, exaggerating the gap between likely and unlikely tokens); τ >1,使其平坦化 (使模型的选择变得更加随机/多样化,因为它缩小了最可能和最不可能的词元之间的相对差距); τ = 1 让分布保持不变.

**交易.**温度是多样性/一致性交易的表格,而不是单独的采样策略它通常与下面的缩短采样策略之一相结合,*哪一个*词元甚至在温度应用之前才有资格.

### 顶部样本

**机械.**限制采样只限于每一步的 k 具有最高概率的词元 (排斥其余的词元,重新正常化它们的概率为1),然后随机从该限制的集合中采样 (可选采用温度).

**交易.**防止模型从未采样一个非常不可能的词元 (从完整分布中纯随机采样偶尔可以做,产生不一致的输出),同时仍然允许可行的候选人之间的有意义的随机性/多样性.固定的k可以在不同情况下不适合,尽管有时只有2-3个真正可行的下一个词元 (而顶级k=40将允许不合理的),有时有数十个大约同样好的选择 (而一个小的固定的k将切断合法的多样性).

### 核 (上-p) 样本采集

**起源.**霍尔茨曼等人",神经文本退化奇怪的案例" (2019).

**机械.**限制抽样只限于最小的最高概率词元组,其累计概率至少为p (例如,p = 0.9意味着"继续添加下一个最有可能的词元,直到保持的集合覆盖90%的总概率质量",然后从动态大小的集合中抽样).

**为什么这很重要.**由于符合条件的集合的尺寸适应模型的分布在每个特定步骤上是如何"高峰"或"平坦" (一个具有主导性的词元的自信预测给出了一个小的符合条件的集合;一个不确定的预测给出了一个更大的集合),核样本处理"只有少数好的选择"和"许多大致相同的选择"情况都比固定的顶级k更优雅,并且大多由于这种情况,成为了,除了温度之外,大多数部署的文本生成系统的标准默认样本配置.

## 为什么仅使用自动降解器的模型,

这值得指出,这是其自己的观点,与一般的"为什么只有解码器赢得了"讨论不同.[transformer-architecture.md](../03-deep-learning-architectures/transformer-architecture.md):文本本质上是序列和分离式的 (句子有一个确定的左到右顺序,每个位置都有有限的代码词汇可选择),这对自行降级框架进行了不寻常的匹配,特别是不像,例如,一个图像,它没有单个"自然"生成顺序,并且是持续的 (像素强度),这是为什么扩散 (见 图像) 的部分[diffusion-models.md](diffusion-models.md)),而不是纯粹的自动降低,成为图像的主导 (尽管自动降低的图像/视频生成,一次预测一个补丁或框架,仍然是一些系统中的活跃,非轻微的替代方法).

## 复发和退化问题,减轻

**问题是什么?**纯粹最大化可能性的解码策略 (贪的解码,尤其是光束搜索) 经验上往往产生**退化**文本 重复循环 (相同的句子或句子重复字面),通用/混合短语,以及特征着人类写的好文本的各种和特点的普遍缺乏.这不是任何单个组件中的错误;这是"模型分配的序列"和"人类认为最好的序列"是相关的,但不是相同的目标,而贪/光线搜索解码对前者进行了特别优化.

**减轻性.**
- **复制/频率处罚**直接降低已在生成输出中出现的词元 (或 n 克  连续词元的序列) 的概率,从而阻止字面循环.
- **核/顶部p采样,温度**通过在可信的候选人中引入控制的随机性,这些候选人避免了纯粹贪/光线搜索解码的高概率循环.
- **后培训方法**超越解码时间修复,例如RLHF (见[rlhf-and-alignment.md](../05-training-methodology/rlhf-and-alignment.md)) 直接训练模型,以优先选择人类实际想要的多样性,高质量的产品,而不是仅仅依赖于推理时间采样技巧,而不是基于基模型的退化趋势.

**现状.**实际上,从2026年开始,基本上所有部署的对话性LLM都采用了核/顶部P样本 (或与此密切相关的精炼) 的某种组合,[05-培训方法](../05-training-methodology/)解码策略和培训方法一起工作,而不是相互替代.

## 较量表

|战略|确定性?|主力|主要的弱点|
|---|---|---|---|
|贪的解码|现在|简单,快速|复制/通用;没有看头|
|射线搜索|是的 (固定光束宽度) |找到更高概率的完整序列|能对开放式生成的淡淡/退化文本进行过度优化|
|顶部样本|没有|限制最坏的词元选择|固定 k 不适应分布形状|
|核 (上-p) 样本|没有|适应可接受的配送信任设置 |需要按使用情况调整p (通常是温度) |
