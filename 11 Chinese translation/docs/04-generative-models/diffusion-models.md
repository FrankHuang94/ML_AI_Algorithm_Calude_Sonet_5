# 扩散模型

扩散模型是截至2026年对图像,视频和音频生成的主导方法.本文件涵盖了方法核心的前进/反转过程,使其成为实用的DDPM公式,与基于分数的生成模型的连接,驱动大多数部署的系统的隐藏扩散架构以及用于引导生成的分类器指导技术.

## 往前 (噪音) 和往后 (声) 的过程

**核心想法.**接下来训练一个神经网络扭转这个过程,从纯噪音开始,逐渐删除一次小量的噪音,在许多步骤中,直到一个现实的图像出现.如果网络真的学会了逐步扭转噪音过程,运行它从新样本的随机噪音 (而不是从一个现实图像中获得的噪音) 应该产生全新的,现实的图像.

```
   FORWARD (fixed, not learned): gradually add noise
   x₀ ──► x₁ ──► x₂ ──► ... ──► x_T
  [clear    [a little  [noisier]      [pure
   image]    noise]                    static]
   🖼️  ───►  🖼️̷  ───►  ▒🖼️  ───►  ▒▒▒  ───►  ▓▓▓

   REVERSE (learned): a network removes a little noise at each step
   x_T ──► ... ──► x₂ ──► x₁ ──► x₀
   ▓▓▓  ───►  ▒▒▒  ───►  ▒🖼️  ───►  🖼️̷  ───►  🖼️
  [start from        (network predicts & subtracts        [brand-new
   fresh noise]       the noise, step by step)             realistic image]
```

**为什么要这样设置这一代人?**直接训练一个网络直接在一个拍摄中将随机噪音映射到现实图像上是一个非常难以学习的功能 (见GAN)[gans.md](gans.md)通过"声"来解除一些噪音,可以在每一步都学会得很好,尽管需要许多步骤 (通常是数十到几百个) 完成一代.前进 (噪音) 方向根本不需要学习. 只是"添加高斯噪音" 这意味着你可以免费生成无限的训练对:拍下任何真实图像,添加已知的噪音量,并要求网络预测你添加的噪音. 这种免费,丰富的监督是为什么火车如此稳定的原因的一个很大部分.

## 断扩散概率模型

**起源.**霍,贾因,阿贝尔, "谴责扩散概率模型" (2020年),建立在早期基于扩散的生成模型理论 (索尔-迪克斯坦等人,2015).

**核心机制 前进过程.**定义一个固定的 (未学到的) T 步骤序列,在每个步骤 t,一个小量的高斯噪音被添加到当前 (越来越噪音) 图像 xt−1产生xt:

```
xₜ = √(1 − βₜ) · x_{t-1} + √βₜ · ε,     ε ~ N(0, 1)
```

节点 (t) (一个小值,按照一个固定的时间表跨步) 控制在步骤 t 添加的噪音量._ (T) (毕竟是T步骤) 是从实际目的中无法区分于纯粹的随机噪音, 在任何步骤 t 时可以直接从原始图像 x0 计算,而不需要在训练中实际模拟所有中间步骤.

**核心机制是反向过程 (实际上学到的).**网络 εθ (由可学习的权重 θ 参数) 训练以预测在给定的步骤中添加的噪音 ε,考虑到噪音图像 xt 和步骤号码 t:

```
Loss = 𝔼_{x₀, ε, t} [ ‖ε − εθ(xₜ, t)‖² ]
```

通过:为训练,拍摄一个真实图像 x0,选择一个随机步骤 t,添加相应的噪音量以获得 xt (使用上述单式快捷方式 不需要模拟每一步),并训练网络以预测确切的噪音添加了,只考虑到噪音结果和步骤数.这是简单的回归问题 (MSE损失 见[loss-functions.md](../01-foundations/loss-functions.md)具有清晰,直接计算的目标 比GAN的对抗目标更稳定.[gans.md](gans.md)由于没有第二个同时变化的网络来追赶.一旦训练,生成从纯粹的随机噪音 x开始运行._通过使用训练有素的网络噪音预测来计算一个稍微低噪音的xt−1,直到一个清洁的x0.

**为什么这很重要.**通过使用更稳定,更容易扩展的培训程序,DDPM证明了这种噪音预测框架可以产生与GAN (而且在接下来的几年内,更好的) 竞争性的图像样本.

## 基于分数的生成模型 (短线连接)

**名称和定义**基于得分的生成模型 (Song, Ermon,同事,2019-2021) 框架生成**评分函数**与数据本身相比数据分布的记录概率梯度 (x log p(x)) 在许多不同的噪音水平,并使用该学习的分数来通过与兰杰文动态相关的样本采集程序 (以物理为灵感的静止样本采集方法) 引导样本从纯噪声向数据分布的高概率 (现实) 区域.

**连接到DDPM.**结果显示,DDPM的噪音预测目标和基于分数的方法的分数匹配目标是数学上非常紧密相关的. 预测添加到样本的噪音基本上相当于估计在噪音水平上的分数函数,直到已知规模因素. 这种联系在后来的研究中正式化 (特别是Song等",通过斯托哈斯式差异方程进行基于分数的生成建模",2021年),将最初看起来像两个独立的研究方向一样的东西统一成一个单一的理论框架,并且自此以来,大部分的扩散模型文献都以互换的方式依赖于两个框架.

## 隐形扩散 (稳定扩散架构)

**起源.**罗姆巴赫,布拉特曼,洛伦茨,埃塞尔,奥默, "高分辨率图像合成与隐形扩散模型" (2021/2022) 稳定扩散的论文.

**它解决了问题.**直接在原始,高分辨率的像素图像上运行完整的噪音/化扩散过程是计算上昂贵的每个多个化步骤都必须处理完整的像素网格.

**核心机制.**首先,用预训练的VAE式编码器将图像压缩成一个更小的隐形表示 (见[vaes.md](vaes.md)这是直接,字面上重复使用VAE架构作为一个组件,而不是仅仅是一个概念平行),在那个较小的隐藏空间中运行整个噪音/释散播过程,并在结尾只使用对对VAE解码器重新解码到完全分辨率的像素.

穿越:由于隐形空间比原始像素更低维度,但仍然捕捉到图像的感知性重要结构 (这是VAE被训练保存的),在那个较小的空间中运行数十到数百个破坏性步骤比在完全像素空间中做同样的事情要便宜得多,同时产生相似质量的最终图像 (经过一个解码步骤后回到像素).这种架构选择在压缩的隐形空间中散,在最后一次解码是使高分辨率基于扩散的图像生成在广泛部署方面具有计算实用性,并且是基础的稳定扩散架构和紧密相关系统.

**文字调节.**为了将此转化为文本到图像系统,一个文本编码器 (从文本提示生成嵌入式见"嵌入式"词典) 用于在每一步 (通常通过跨重视见) 调节表示网络.[transformer-architecture.md](../03-deep-learning-architectures/transformer-architecture.md)图像-隐藏表示和文本嵌入之间的),因此,指责过程是指向产生与提示一致的图像而不是任意的现实图像.

## 类别指导与无类型指导

**类别指导**通过使用单独训练的分类器,从噪音图像xt预测一个类标签 (或其他条件信号),并使用*缩*这种类别可以确定是所需的类别/条件. 这种类别可以有效,但需要专门为此目的培训和维护一个单独的类别模型,这增加了复杂性,并且只支持了单独的类别符训练的任何条件信号.

**无分类指导**(Ho, Salimans, 2022). 训练一个单独的分类器,一个单一的扩散模型,可以在"条件"模式下运行 (鉴于文本提示/条件) 和"无条件"模式 (鉴于没有条件) 中,在一些训练中条件输入被固定定位器所取代. 在生成时,运行模型两方向,并抽出*走了*根据无条件的预测,*走向*条件的比率超过1:1:

```
guided_prediction = uncond_pred + w · (cond_pred − uncond_pred)
```

在哪里 w > 1 是指导尺度 (如何强烈向条件推进). 通过:条件和无条件预测之间的差异代表"条件具体增加什么";放大这一差异 (而不是直接使用条件预测) 推动生成更强烈地反映提示/条件,比一个简单的条件预测单独会,以某种成本对总体样本的多样性,如果指导尺度被推高太高.

**为什么无分类指导赢得了.**它不需要单独的分类器模型,使用任何条件信号 (文字,类标签,图像) 主要的扩散模型都被训练,而不是仅限于特定分类器的输出,并且经验上产生了更好的结果.

## 调整流量和调整流量 (当前一代培训目标)

**这里是为什么属于的.**对于2026年参考,上面的DDPM/score-matching框架是基础,但最新的大规模图像和视频生成的大部分都以一个紧密相关的,略简单的目标训练,称为**流量匹配**(以及它的**调整流量**现在,我们在使用了"图像与文字"的方法, 并且我们在使用的图像和视频系统中,

**简单地说,这个想法.**扩散认为生成是*逆转噪音过程*流量匹配的过程,*速度场*网络在"纯噪音"和"真实图像"之间的任何中间点,预测"我应该朝着什么方向,以及要快的,走向现实数据?" 生成只是从噪音样本到数据样本的预测速度,就像跟踪电流. **调整流量**其他交通工具*直接*直接攻击扩散最大的弱点: 需要生成样本的许多序列步骤.

**如何与传播有关?**流量匹配可以证明,在特定的路径选择下,包括了基于扩散/分数的目标作为特殊情况;这两个是同一家人的成员 (两者都学会从噪音移动样本到数据),实际区别是网络的目标是如何训练预测 (速度与增加的噪音) 和中间路径的形状.对读者来说,重要的结论是: (1) 现代发电机越来越多地训练这种方式,因为它倾向于更简单,使步骤更少,采样更快; (2) 它不会推翻以上的DDPM部分中的任何东西 噪和否定直觉仍然存在; (3) 生态系统 (拉丁空间操作,分类器免费指导,通过转移信息进行文本条件化) 基本上没有改变.

## 为什么扩散成为图像/视频/音频生成的主导

连接从此文件和从[gans.md](gans.md)基本的方法是:稳定,简单,相邻的概率训练 (没有敌对游戏可破坏稳定);强大的实验性样本多样性 (模式崩类型的故障,是GAN的本地,并不是扩散训练的可比较问题);对文字/类型/其他信号的控制性强度进行条件生成的自然,充分理解的机制 (无分类指导),以及通过隐形扩散,特别是通过高分辨率产生以计算合理的成本的实际途径.相同的核心噪音/测量框架已远远超越了静态图像,并将噪音过程扩展到视频 (跨越时间维度以及空间维度) 和生成,这也是为什么在多种方式上成为默认的音频扩散生成方法的一部分.

## 目前的边境状况

扩散模型仍然是截至2026年图像,视频和音频生成的主导方法.与一些替代方案 (特别是GAN,在较小程度上一些新的几步/蒸式扩散变体) 相比的主要实际缺点是推理速度.

几种技术家庭攻击速度问题,
- **较好的样本**(例如,**鱼**培训模型的重新解释,使这一代人能够接受*较少,较大*往往减少数百步到数十步,使样本采集过程变得决定性 (相同的噪音输入总是产生相同的图像,可复制和编辑有用),而无需重新训练模型.
- **更加直的道路**通过几步,可以更容易地穿过轨道.
- **蒸成几步或单步样品**快速的"学生"可以在一步或几步中复制慢的"老师"在许多方面所做的 (一种使用蒸的想法从[pruning-and-distillation.md](../06-inference-optimization/pruning-and-distillation.md)).

在这三个方面,该领域取得了实质性,报告的进展,到达了几步生成越来越实用的程度;然而,在本文写作时,最重要的质量时,多步传播仍然是默认的.
