# 国家空间模型

国家空间模型 (SSM) 是一个作为注意力替代方案提出的序列架构,旨在保持Transformer的长距离建模能力 (见[transformer-architecture.md](transformer-architecture.md)根据该库的质量条,截至2026年,这仍然是一个少数,仍然成熟的方法,而不是一个已经过验证的Transformer替代.

## 动机:二次注意力成本问题

**问题是什么?**自主注意力计算在一个序列中的每个位置对之间的相似性分数 (Q·KT术语涵盖在[transformer-architecture.md](transformer-architecture.md)) 对一个长度 n 的序列,这意味着计算和所需的内存均为 n2 ,这使序列长度翻倍,成本四倍.对于短序列,这很好,但随着文本长度已成长到边界 LLM 的数十万个词元,方形术语成为主导成本,无论是在训练期间,尤其是在推理期间,它与KV缓存相互作用 (见[kv-cache-and-attention-optimization.md](../06-inference-optimization/kv-cache-and-attention-optimization.md)).

**现在,我们要去看看.**如果一个序列架构可以处理每一个新的词元*常数*时间和记忆相对于前列的数量,RNN的复发方式 (见[rnn-lstm-gru.md](rnn-lstm-gru.md)),但没有RNN的消失渐进问题和缓慢,严格的序列训练?状态空间模型在实际意义上是试图带回复性,使用更精心设计的内部机制,特别是以获得序列长度的线性 (而不是方形) 扩展.

## 其他

**名称和定义**S4 (结构化状态空间序列模型) 重新制定了经典连续时间控制理论概念,一个线性状态空间模型,在时间的推移下,一个隐藏状态根据输入驱动的线性差异方程不断演变,成为一种可以作为深度学习序列层使用的形式.

**起源.**郭,戈尔,雷, "结构化国家空间的长序列有效建模" (2021/2022).

**核心机制 (概念性).**连续时间状态空间模型由两个更新规则定义 (以微妙的形式,因为神经网络在单独的词元/时间步骤序列上运行):

```
hₜ = A · h_{t-1} + B · xₜ
yₜ = C · hₜ
```

经历:这种情况结构上与尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉尼拉[rnn-lstm-gru.md](rnn-lstm-gru.md)) 一个从前隐藏状态和当前输入更新的隐藏状态ht. 关键的区别是,S4将对矩阵A进行精心的数学结构 (具体来说,结构化以使它与良好的"记忆"相符) 一个来自同一研究小组的早期相关工作的HiPPO矩阵,旨在使隐藏状态能够在长距离的时间内代表输入的压缩历史) 和对实用性来说非常重要,因为这种反复是*线性*(与RNN的反复不同,它在每一步都通过一个像tanh这样的非线性),整个序列的输出可以计算为**曲**在训练期间,整个输入一次 (数学上相当于解滚复发,但可平行计算,避免了RNN的严格序列训练瓶),同时仍然可以作为推理时间的真正一步一步复发,从而提供每词元的持续成本和内存.

**为什么这很重要.**在长距离序列基准上,S4 专门旨在强调长度依赖模型,表明一个正确结构化的线性复发性可以在非常长的序列上显著超过Transformer和尼拉RNN,同时在线性 (而不是方形) 扩展序列长度上是第一个强有力的实验证据表明,一个无注意力的架构可能是长文本模型的竞争力.

## 选定状态空间

**名称和定义**巴通过制造状态空间模型的核心矩阵 (A,B,C和分辨步骤大小) 扩展S4.**输入依赖性**由电流输入进行动态计算,而不是固定 (与S4一样,对每个位置相同) 作者称之为属性**选择性**.

**起源.**郭,道, "Mamba:选择性状态空间的线性时间序列建模" (2023).

**选择性是为什么重要.**模型对待每个位置的"记得多少与忘记"行为相同,不管内容是一个真正的限制,因为理想情况下,模型希望记住内容关键的词元 (如一次提到的名称) 比填充词元长得多,具体取决于内容,注意力基于内容的权重允许 (见[transformer-architecture.md](transformer-architecture.md)让回归参数成为当前输入的函数,让Mamba选择地决定,每词元,要多多么写入并保留在隐藏状态下,从而缩小了SSM和注意的内容权重之间的表达性差距. 折衷是,这种选择性打破了S4在训练过程中容易对称的清洁"与卷曲的相当"技巧,因此Mamba更改依赖于自定义的硬件意识的并行扫描算法 (一个有效的并行实现回归,专门设计以在GPU上运行良好) 保持训练效率,尽管对输入依赖的回归.

**为什么这很重要.**尽管Mamba在语言建模基准上与类似规模的Transformer进行了竞争,但同时保持了线性时间,每词元的恒定记忆推理.

## 动机

**名称和定义**RWKV (从其重复的四个主要参数矩阵中衍生的缩写:接收,权重,关键,值) 是另一种基于线性重复的架构,开发的目标是将Transformer式并行的训练与RNN式恒定记忆推理结合起来.

**起源.**等,"RWKV:重新发明RNN为Transformer时代" (2023年),最初是开源社区项目.

**核心机制 (简单).**RWKV使用一种有明确的衰变术语的线性注意力类似机制 (旧信息以结构的方式随时间推移减重),类似于S4,可以计算在训练期间作为可并行的形式或在推理过程中作为有效的复发.

**现状.**较小但活跃的开源流程,持续代;用于一些开放权重模型版本,评估其推理效率,尽管它尚未达到主流的边界实验室采用Mamba式SSM或标准基于注意力的Transformer.
