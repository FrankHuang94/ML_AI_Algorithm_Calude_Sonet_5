**名称和定义**循环神经网络一次处理一个序列的元素,保持一个**隐藏状态**它们每次更新,然后将它们传递到下一步.

**起源.**复制网络架构可以追溯到1980年代 (Rumelhart,Hinton,Williams等);今天作为基线使用的特定"简单的RNN"公式通常归因于Elman (1990).

**核心机制.**

```
hₜ = tanh(W_h · h_{t-1} + W_x · xₜ + b)
yₜ = W_y · hₜ + b_y
```

通过:每次步 t,网络将之前隐藏的状态h结合在一起_通过一个非线性 (tanh,一个类似于sigmoid的压缩函数,但从 −1到 1),并产生一个新的隐藏状态 ht._,_,_) 在*每一个*时间步骤 是一种时间上的权重分配形式,类似于CNN的过器在空间位置上如何分配 (见[cnn-family.md](cnn-family.md)) 允许RNN处理任何长度的序列,具有固定数量的参数. yt,一个可选的每步输出,由隐藏状态计算,并且可以在每一步 (例如,标签每个词) 或仅在最后一步 (例如,分类整个序列) 中生成.

**为什么这很重要.**循环配方使神经网络能够自然地处理变长序列数据,而不需要固定输入尺寸,使用隐藏状态作为迄今为止处理的所有压缩"记忆".

## 消失/爆炸梯度问题,具体

**问题是什么?**训练一个RNN使用**时间后延伸 (BPTT)**你在所有T时间步骤中滚动复发 (处理它为一个非常深的T层的输送网络,所有都共享相同的权重) 并通过那个滚动链中反向扩散损失梯度._通过一个步骤,每步骤一次乘以 (大约) 相同的因子T,

通过具体说明:如果每步乘因子是,说,0.9,那么100步后梯度已经被扩大大大约0.9^100 ≈ 0.00003 ,它已经消失了,并且网络实际上不能学习依赖度超过几十步后面,因为描述"80步前的输出取决于这个早期输入"的训练信号从来没有幸存下来的反向旅行有意义的大小.相反,如果每步因子是类似于1.1,梯度通常爆炸:1.1^100 ≈13.781 一个巨大的,破坏稳定的值 (这是同一种爆炸式梯度现象[optimization-algorithms.md](../01-foundations/optimization-algorithms.md)实际的RNN位于纯消失和纯爆炸之间,取决于W的自有值._但实际上,尼拉的RNN可靠地努力学习超过大约10-20个时间步骤的依赖性,这对语言 (句子的含义可能取决于一个词的许多词元之前) 和其他长序列来说是一个严重的限制.

**为什么这很重要?**这种具体故障模式 长距离依赖度根本无法生存训练 是下面的LSTM和GRU的直接动机,后来,完全放弃反复,以支持Transformer的注意力机制,这给每个位置一个直接的,单步的路径到其他位置 (见[transformer-architecture.md](transformer-architecture.md)) 而不是随着序列长度而增长的梯度路径.

## 长期短期记忆 (LSTM)

**名称和定义** LSTM是一个复发单元,并加上一个明确的单元.**细胞状态**通过一个单独的存储道,可以在许多时间阶段中运输信息,**门户**控制被添加到,删除到,并从记忆中读取的信息.

**起源.**霍克莱特,施密德伯,"长短内存" (1997)  特别,这在深度学习繁荣之前15年,它解决的消失梯度问题被同一作者在早期的作品中确定 (霍克莱特的1991年文凭论文).

**核心机制是门,一个接一个.**一个LSTM既保持隐藏状态 ht (如尼拉 RNN) 也保持独立的细胞状态 ct. 每次步骤,三个门 (每个小神经网络层通过sigmoid输出0到1之间的值,作为"多多让通过"拨号) 控制信息流动:

- **忘记门** ()_[_没有任何其他方法.]_f) 决定存储与丢弃现有细胞状态中的多少.给定的内存维度的近0值意味着"忘记";近1意味着"保持它".
- **输入门**子_其他[_没有任何其他方法.]_决定候选人新值的数量 (c̃t = tanh(W_其他[_没有任何其他方法.]_写入细胞状态.
- **输出门** ()_其他[_没有任何其他方法.]_决定该 (更新) 细胞状态的多大部分将作为新的隐藏状态暴露.

电池状态更新是:

```
cₜ = fₜ ⊙ c_{t-1} + iₜ ⊙ c̃ₜ         (⊙ = element-wise multiplication)
hₜ = oₜ ⊙ tanh(cₜ)
```

图像的图像是最清楚的方法来了解为什么这个设计修复了消失梯度**作为传输带的细胞状态**直接穿越时间,有加或删除的门,但从来没有以权重矩阵重复乘以:

```
             forget gate         input gate
             (erase some?)       (write some?)
                  │                   │
   c_{t-1} ──────►⊗────────────────►(+)──────────► cₜ   ← the "conveyor belt":
   (old memory)   ▲                   ▲              (mostly just carries memory
                  │                   │               forward, lightly edited)
                 fₜ         iₜ ⊙ c̃ₜ (candidate new info)
                                                     │
                                          output gate⊗──► hₜ (what to expose now)
                                                     ▲
                                                    oₜ
```

通过:忘记和输入门一起决定,按内存维度, "保留旧值,主要用新信息取代它,或是两者兼并",关键的是,细胞状态更新由一个增值术语主导 (ft  c_{t-1}加上它  c̃t) 而不是尼拉 RNN的隐藏状态的重复矩阵乘法.当忘记门接近1时,信息可以通过 ct 路径通过许多时间步骤流动,但几乎没有衰退,因为沿着路径没有权重矩阵重复乘法.[cnn-family.md](cnn-family.md)炼深度的技巧是*添加剂*由于在线路线的低调,它可以通过梯度进行一次性降低.

**为什么这很重要.**LSTM可以可靠地学习跨越数百个时间步骤的依赖性,在语言建模,翻译和语音任务上显著超过尼拉RN,并成为2000年代末 (一旦计算抓住了深度LSTM培训) 到2010年代中期的基本所有序列建模工作的默认复制架构.

## 关闭回应单位

**名称和定义**GRU 是简化替代的LSTM,将细胞状态和隐藏状态合并成一个,并将三门缩小到两个.

**起源.**乔及其他研究人员"学习用RNN编码器-解码器进行统计机器翻译的语句表示" (2014).

**核心机制 (简单).**格鲁有一个**更新门**有效地将LSTM的忘记和输入门的作用结合在一起) 和一个**复设门**由于有较少的门口和没有单独的细胞状态,GRU的参数比相同的隐藏大小的LSTM少.

**现在的情况.**像LSTM一样,GRU在2026年起已被基于Transformer的架构大大地取代,但对于较小规模的Transformer进行过度处理的应用,这两者仍然是合理的,较低计算的选择.

## 排列2排列的架构

**名称和定义**序列到序列 (seq2seq) 模型将输入序列映射到潜在不同长度的输出序列,使用一个**编码器**通过RNN/LSTM将整个输入处理成一个固定尺寸的总结向量,**解码器**根据该总结,一个元素生成输出序列的RNN/LSTM.

**起源.**苏茨基弗,维尼尔斯,莱, "随机学习与神经网络" (2014);乔等 (2014,同一个论文如GRU以上) 引入了密切相关的编码器-解码器框架同时.

**为什么这很重要.**2seq为机器翻译,总结和回答问题等任务提供了清洁的,一般的配方,任何在不需要任务特定架构的情况下映射一个序列到另一个任务的任务,并且是转换器之前神经机器翻译的主要范式.

**瓶问题.**基本的设计是*整体*输入序列将其输入到一个固体尺寸的单个向量 (编码器的最后隐藏状态),该解码器必须依赖于它生成的一切.对于长入口来说,这是一个严重的信息瓶.一个单个向量,无论多大,都在努力保留一个长句子或文档中的所有相关细节.这项限制正是前变体注意力 (下面) 发明的解决方案.

## 长期关注 直接桥梁到变革者

**名称和定义**注意,在这个原始背景下,让解码器回顾*所有的*在每个解码步骤中,编码器隐藏状态 (每输入位置一个),动态计算它们的权重组合,而不是仅依赖于单个固定的总结向量.

**起源.**巴哈达纳,乔,班基奥, "通过联合学习协调和翻译的神经机器翻译" (2014);卢昂,帕姆,曼宁, "基于注意力的神经机器翻译的有效方法" (2015);该书提出了简化,计算上更便宜的变体 (这就是为什么你会看到"巴哈达纳注意"和"长时间注意"都被引用为相关但不一样的历史机制).

**核心机制.**在每个解码器步骤中,计算解码器目前隐藏状态和*每一个*通过软max将这些分数转换为权重 (见 [loss-functions.md](../01-foundations/loss-functions.md));使用这些权重 (a **文本向量**);使用本文向量,以及解码器的隐藏状态,帮助生成下一个输出.

通过:而不是通过一个瓶向量强迫整个输入句子,解码器可以"回头看"输入的特定部分,最适合目前正在试图生成的任何东西. 例如,在翻译句子时,解码器可以最强烈地关注源词或句子,与即将输出的词相符,类似于人类翻译者的眼睛可能会回头看源句子的特定部分.

**直接通往Transformer.**这种机制消除了seq2seq瓶,并导致了翻译质量大幅上升.[transformer-architecture.md](transformer-architecture.md)):核心想法是计算查询和一个组候选人的相关性分数,将它们软max分成权重,并取一个权重的总数.*每一个*位置到*其他*通过消除连续,一次步骤处理瓶,限制RNN在现代硬件上如何平行化,并完全回避消失的梯度-长度序列问题,因为注意力给每对位置一个直接的,单步计算路径,无论它们在序列中有多远.
