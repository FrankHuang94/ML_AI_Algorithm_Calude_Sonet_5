# 图表神经网络

图神经网络 (GNNs) 扩展深度学习到自然结构为图的数据 节点 (实体) 通过边缘 (关系) 连接而不是CNN所假设的网格式结构 (见 [cnn-family.md](cnn-family.md)图结构数据的例子:分子 (原子作为节点,化学结合作为边缘),社交网络 (人作为节点,友作为边缘),知识图 (实体作为节点,关系作为边缘).

## 传递信息框架

**名称和定义**传递信息是几乎所有现代GNN使用的一般计算模式:在每个层次上,每个节点从其直接的图表邻居收集信息 ("消息"),结合它们,并使用结果更新自己的表示.

**核心机制.**

```
message_i = AGGREGATE({ h_j : j ∈ neighbors(i) })
h_i' = UPDATE(h_i, message_i)
```

```
   Before one message-passing layer      After: node A has gathered from B, C, D
        B                                       B
        │                                       │
   C ── A ── D                             C ── A ── D
                                                ▲
   A's new representation = UPDATE(            A now "knows about" its
     A's old value,                            immediate neighbors B, C, D.
     AGGREGATE(B, C, D) )                      After a 2nd layer, it also knows
                                               about B/C/D's neighbors (2 hops), etc.
```

通过:对于每个节点 i,看看它的所有直接连接的邻居节点 j,结合它们的当前表示 h_j某种方式 (AGGREGATE 通常是总和,平均或最大,因为邻居数量因节点而异,并且集成需要处理变量尺寸输入),并使用这种结合信息,以及节点的当前表示,计算其下层表示 (UPDATE 通常是一个小的神经网络层).堆叠k消息传递层允许每个节点的最终表示包含来自邻居到k图跳的信息.[cnn-family.md](cnn-family.md)),除了相关的"邻居"之外,这里定义为图形连接而不是空间邻近. (事实上,CNN可以被视为传递信息的特殊情况,在一个非常正规的网格形图上,每个像素的邻居是周围的像素,自觉作为传递信息的信息,在一个完全连接的图上,每个词元是其他词元的邻居.

**为什么这个框架很重要?**它给了GNN的内置结构假设 (诱导偏见查看词典) 使CNN对图像产生效果:而不是把每个节点对都视为同样可能相关 (像一个完全连接的网络一样,完全忽略了图形结构),信息传递在假设直接连接的节点是更新节点的表示最相关的信息来源,这通常是图形结构数据的现实假设.

## 图形缩网络 (GCN)

**起源.**基普,韦林, "与图形卷积网络的半监督分类" (2017).

**核心机制.**GCN是一个简单的信息传递实例:它通过 (度正常化) 权重平均值进行正常化,使得许多邻居的节点不会自动主导集成,仅仅是通过更大的原始总数,然后是共享的线性转换和非线性,在每个节点上应用相同 (权重共享,再次类似于CNN过器的权重如何在空间位置上共享).

**为什么这很重要.**GCN是首个证明强大,简单,广泛可复制的GNN变体之一,在标准图标上表现出强大,广泛的结果 (如节点分类预测每个节点的标签使用其自己的特性和邻居的特性和连接),并且仍然是该领域的标准,已被理解的基线架构.

**限制.**原始的GCN配方是**转导**它是定义在训练期间看到的固定,特定图表上,并不会自然概括为预测新的节点或完全新的图表在训练期间没有看到.

## 图表

**起源.**汉密尔顿,,莱斯科夫, "大图上的诱导性表示学习" (2017).

**核心贡献**图表 (简单和简单) 传递信息**诱导性**能够将其通用到训练中从未见过的节点和图表 通过学习一般的集成*功能*为了实现大型图表的可扩展性,随机使用*采样*每个节点的邻居在每个层的固定尺寸子集,而不是把它们全部聚合在一起 (对于现实世界的图表来说很重要,其中一些节点可能有数百万邻居,例如一个非常受欢迎的社交媒体帐户,使得完全的聚合非常昂贵).

**为什么这很重要.**图表SAGE的诱导能力使 GNN 对于现实世界,大型,不断变化的图表 (如社交网络每秒获得新用户和连接),

## 图表注意力网络 (GAT)

**起源.**维利克科维奇等人, "图形注意力网络" (2018).

**核心贡献**基因研究系统将GCN的固定,基于度的邻居平均取代为学习,基于内容的注意力机制 (直接类似于[transformer-architecture.md](transformer-architecture.md)每个节点根据两个节点的当前表示计算对其每个邻居的注意力权重,并使用这些学习的内容依赖权重而不是固定结构公式来汇总邻居信息.

**为什么这很重要.**这使得模型了解到,对于给定的节点的表示,某些邻居比其他邻居更重要 (而不是把所有邻居都视为同样重要的模块,他们的程度), 内容的关注对本库其他地方的固定位置/结构权重提供了相同的质量益处

## 使用情况

- **分子模型.**作为图表表表现分子 (原子作为节点,键作为边缘) 和使用 GNN来预测分子特性 (溶性,毒性,结合性) 或产生新型候选分子 计算化学和药物发现领域的主要和不断增长的应用领域,其中 GNN对图形结构化化学数据的自然适应给它们提供了对需要分子不重格式化成网格或序列的架构结构优势.
- **建议系统.**模型用户和项目作为节点在双边图 (边缘代表购买或点击等互动),GNN基于的方法可以比传统的矩阵因子化基于推方法更自然地传播信息在图中 (例如"类似于您喜欢这个项目的用户").
- **知识图表.**作为图表表表现结构化的事实 (实体关系实体三倍) 并使用 GNN 来完成链接预测 (即使没有明确记录) 或实体分类等任务.

## 现状

基因网络仍然是真正的标准,最自然的建筑选择,特别是真正的图形结构数据 (分子,社交/引用网络,知识图) 这是一个领域,其结构性适应性给它们在通用架构上提供了真正的,持久的优势,类似于CNN在Transformer主导的时代中也保持了真正的网格结构图像数据的优势.基因网络网络是该领域相对较专业的角落,与一般用途基于Transformer的LLM的巨大投资相比,但在其适用的领域 (特别是计算化学/药物发现和大规模工业推系统) 里,它们仍然存在着实质性,不减少的生产使用,截至2026年.
