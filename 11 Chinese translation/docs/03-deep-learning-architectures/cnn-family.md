# 美国CNN家庭

卷积神经网络 (CNN) 是对图像进行深度学习的工作的架构家族,其核心构建块卷积仍然在现代视觉系统中使用,即使纯 CNN 部分地为最大规模模型提供了视觉转换器.该文件从零构建卷积和汇集,然后通过ResNet和EfficientNet从LeNet传递到谱系,并简短地描述检测架构作为应用使用案例.

## 曲和聚合机械,从零开始

**图像上完全连接的层面的问题.**标准的完全连接层将每个输入值与每个输出神经元连接到自己的独立权重.对于一个图像来说,这是一个不合适的两个原因:参数数数量爆炸 (一个256×256 RGB图像有~单个完全连接到另一个196,000个值的层次需要10^10的权重),并且完全丢弃了图像的空间结构. 层没有内置的概念,即附近的像素是相关的,或者像素的图案代表图像左上边边的边缘是相同的图案.

**缩.**曲的层则应用了小学的**过器**(或**核子**一个小的权重格,例如3×3或5×5) 通过整个图像滑动,在每个位置计算过器和其下面的本地像素补丁之间点产品.

```
output[i, j] = Σ_m Σ_n  input[i+m, j+n] · filter[m, n]
```

通过:在每个位置 (i,j),您乘以元素对输入的相应补丁的过器权重并将结果总结成一个输出值,然后将过器滑过一个 (或多) 像素,然后重复.这里具体是3×3"垂直边缘探测器"过器滑过图像的一块补丁:

```
   Image patch          Filter (vertical         Element-wise
   (pixel values)        edge detector)           multiply & sum
   ┌───┬───┬───┐         ┌────┬───┬────┐
   │ 0 │ 0 │ 9 │         │ -1 │ 0 │ +1 │          (0·-1)+(0·0)+(9·+1)
   ├───┼───┼───┤    ⊛    ├────┼───┼────┤    =     +(0·-1)+(0·0)+(9·+1)   =  +27
   │ 0 │ 0 │ 9 │         │ -1 │ 0 │ +1 │          +(0·-1)+(0·0)+(9·+1)
   ├───┼───┼───┤         ├────┼───┼────┤
   │ 0 │ 0 │ 9 │         │ -1 │ 0 │ +1 │          → large positive = "edge found here"
   └───┴───┴───┘         └────┴───┴────┘
   (dark left,           (fires on left-to-        A flat patch (all same value)
    bright right)         right brightness jumps)   would sum to ≈ 0 — no edge.
```

过器输出一个很大的数字,无论图像的地方匹配其模式 (这里,一个黑暗到亮的垂直过渡) 和接近零的地方. 滑动这个相同的过器在整个图像,你得到一个"地图"的任何地方边缘出现.*其他*子的子权重在每一个位置都被重复使用**权重分**由于过器在任何地方都应用相同的过器,所以过器学会在图像中任何地方检测到的模式 (如垂直边缘) 不仅在一个固定位置上.一个卷积层通常学习许多过器并行 (例如64个不同的3×3过器),每个产生自己的输出"道",因此层可以同时检测到许多不同的本地模式.*学习*上述边缘检测器是说明性的,但在训练有素的网络中,过器来自数据 (早期层可以可靠地学习像这样的边缘和颜色检测器;后层学习对纹理,对象部分和最终的整体对象的检测器).

**聚在一起.**聚合层通过将小区域总结成一个值来减少其输入的样本**总结**(每一个小区域,例如每一个2×2区块,都取最大值) 或**平均聚合**聚合没有学习的权重;这是一个固定的总结操作. 通过:聚合减少通过网络流动的数据的空间分辨率 (例如,2×2最大聚合量将高度和宽度都减半),从而减少了后续层的计算,并增加了一定程度的**翻译不变**(一个小的转移,在输入中出现一个特征对合并输出的影响较小,因为合并操作总结在一个本地社区,而不是读取一个确切的像素位置).

**堆叠层.**一种典型的CNN交替曲 (通常跟随ReLU等非线性) 和聚合层,以便早期层检测到简单的本地模式 (边缘,颜色斑点) 和后层 运行在早期层的已经抽象输出,并覆盖原始输入的逐渐更大的有效区域 (一个不断增长的**接收场**) 检测越来越复杂的复合模式 (纹理,物体部分,整体物体).

## 网

**起源.**根据同一个组织在1980年代末至1990年代初的早期工作,LeCun等人"应用在文档识别中的基于基层的学习" (1998).

**为什么这很重要.**莱内特-5是第一个在实践中证明的CNN,在一个真正的实际任务 (手写数字识别检查处理), 缩加合架构,通过后传传训练端到端,可以击败手工工程的特征提取管道.

**现状.**仅仅是历史/教育的,其规模 (几千参数) 根据现代标准是微不足道的,但其结构 (缩 →集结 →集结 →集结 →集结 →完全连接的分类器头) 仍然是CNN每次进一步阐述的基本模板.

## 亚历克斯网

**起源.**克里谢夫斯基,苏茨基弗,希顿, "与深度缩神经网络的图像网分类" (2012).

**为什么这很重要.**亚历克斯网在2012年ImageNet大规模视觉识别挑战赛中取得了巨大胜利.  通过大差距击败下一个最佳 (非深度学习) 方法.~亚历克斯网 (AlexNet) 已经在 GPU 上训练,这本身就是当时的重要实用选择,它可以显著超过上十年的手工计算机视觉管道.它使用了 ReLU 激活 (比之前的 sigmoid/tanh 激活更快训练,因为 ReLU 的梯度不会减少大正输入),[regularization-techniques.md](../01-foundations/regularization-techniques.md)),以及数据增强,其中一些仍然是标准做法.

**现状.**历史 其具体的建筑今天不使用 但这是这篇论文的历史部分 (见[历史](../08-history/)) 作为定义场的"图像网时刻".

## 果

**起源.**赛蒙扬,齐斯曼, "大规模图像识别的非常深层次转变网络" (2014).

**核心贡献**维格G证明,堆叠许多小型 (3×3) 卷积过器,而不是使用更少的,更大的过器,像AlexNet的样子可以实现更好的准确性,因为堆叠两个3×3卷积给出与一个5×5卷积相同的有效接收场,同时使用更少的参数,并增加了额外的非线性性 (允许网络学习更具表达性的函数,相同的接收场大小).维格G的架构也显著简单和均 (仅有3×3卷积和2×2集结,重复),这使得分析和重复使用作为其他任务的特征提取器变得容易.

**现状.**很少像现在一样使用 (其130多万个参数是现代标准的高度标准很大,而且效率低下),但VGG式特征提取器仍然在某些特定应用中使用,例如图像生成的感知损失函数 (测量两个像是如何与预训练的VGG网络内部特征"看起来"相似的,而不是比较原始像素).

## 跳过连接,在深处解决消失梯度

**起源.**他,张,伦,孙, "对图像识别的深度残留学习" (2015).

**解决了这个问题.**在ResNet之前,仅仅堆叠更多层次, 无法可靠地提高精度,*培训*获得了准确性 (不仅仅是通用化)*最糟糕的*对于非常深层的平线网络来说,这表明优化问题,而不是过度适应.[optimization-algorithms.md](../01-foundations/optimization-algorithms.md)其他[rnn-lstm-gru.md](rnn-lstm-gru.md)):由于损失梯度通过许多堆叠层反复扩散,它被每层的本地衍生子乘以一次,如果这些衍生子往往不到1 (常见于和非线性层的层,甚至是基于ReLU的网络在极度深度的持续问题), 达到早期层的梯度可以缩小到零,

**核心机制.****剩余 (跳转) 连接**直接将一个层块的输入添加到其输出:而不是一个块学习一个完整的转换 H(x),它只学习了*剩余物*区块的实际输出是F(x) + x.

```
output = F(x) + x
```

通过: "+x"术语为梯度通过网络流向后面提供了直接,无障碍的路径. "输出"梯度与"x"相对于总是包含一个清洁的"1"术语,除了F(x) 支部所贡献的任何东西外,因此梯度不能仅仅从通过该块消失到零,无论F(x) 自己的梯度如何缩小. 这也意味着,如果给定的块的转换不有用,网络可以有效地学习使F(x) ≈ 0,让块通过不变的输入更容易学习,而不是在平坦 (非残余) 块中进行相当的身份映射.

**为什么这很重要.**雷斯网使训练网络具有100多层的实用性 (原始纸质训练版本高达152层),可靠地提高了深度,而之前的平坦架构已经停滞在20-30层左右.这是一个基本的解锁,残余连接继续成为一个基本上普遍的架构元素,用于Transformer (见[transformer-architecture.md](transformer-architecture.md)) 和近乎每一个深层建筑自那以后 (也被讨论为隐含的调节剂在[regularization-techniques.md](../01-foundations/regularization-techniques.md)).

**现状.**ResNet变体仍然在许多视觉任务的活跃生产中使用 (特别是计算/延迟预算偏好CNN的视觉Transformer,或者在较小的数据集中,下见的附加诱导偏见有助于),并且跳转连接在现代深度学习中基本上是普遍的,远远超出了视觉.

## 开始 / 谷歌网

**起源.**谢格迪等, "与转变更深入" (2014).

**核心贡献**启动模块运行了几个不同的过器尺寸 (例如1×1,3×3,5×5) 和聚合操作 *并行*网络可以在每个阶段同时捕获多个空间尺度的模式.它还将1×1卷曲作为一个廉价的方式来减少道数量,在昂贵的更大的卷曲之前,大幅削减计算.

**现状.**它的多层次并行分支理念影响了后来的建筑设计,但谷歌LeNet/Inception本身今天不常被部署;高效Net和ResNet家族架构是更常见的实际选择,视觉变革器主导了最大规模的制度.

## 效率网 复合规模化

**起源.**坦,勒, "高效网:重新思考缩神经网络模型规模化" (2019).

**核心贡献**之前的工作通常在一次上扩大CNN在一个维度上更多层 (深度),每个层 (宽度) 更多频道或更高的输入图像分辨率. 效率网的关键见解是,这些三个维度相互作用,并且在一个固定的比例中,通过小的网格搜索来确定,比仅扩展任何单个维度更好.**复合扩展**方法,结合通过神经架构搜索 (而不是手工设计的自动搜索过程) 发现的精心设计的小型基础架构,产生了一系列模型 (EfficientNet-B0到B7) 具有比上次手工设计的CNN在发布时的每参数和FLOP准确性明显更好.

**现状.**效率网及其后代仍然是具有实际计算/延迟限制 (例如设备或边缘部署) 的视觉任务的强大,效率为主导的选择,尽管非常大的视觉工作负载越来越多地转向视觉Transformer变体.

## 检测架构 (应用使用情况,简介)

发现物体 在图像中定位和分类多个物体 是CNN功能的主要应用,在这里简短地描述为一个使用案例而不是在完整的建筑深度.

- **美国广播公司**(R-CNN,Fast R-CNN,Faster R-CNN  Girshick等,2013-2016) 通过提出一个可能包含对象的图像的候选区域,然后使用CNN的功能进行分类和精炼每个建议区域.
- **子**("You Only Look Once"  Redmon et al., 2016) 将检测重新构成一个单次回归问题:通过网络的前进通过直接预测整个图像的边界框和类概率,而没有单独的区域提案阶段.这相当快,使YOLO家族模型 (自那以后经历了许多代) 成为实时检测应用的标准选择.

**现状.**两个家庭仍然在生产中使用,根据准确性/速度的交易选择,给定的应用需要两个阶段的探测器,当最大准确性比延迟更重要时,单通路探测器 (YOLO家族) 对于实时限制.

近距离的像素比远隔离的像素更重要,直接编码到卷积操作中 (一个**诱导偏见**使它们具有数据效率:它们可以在相对较小/中等数据集上实现良好的准确性,因为它们不必从零开始学习"近距离的像素相关".视觉Transformer (从[transformer-architecture.md](transformer-architecture.md)随着CNN的应用程序的发展,它将会成为一个更有效的技术,可以让用户学习更灵活,更少局部限制的模式,但只能通过非常大的训练数据集来获得回报,因为模型必须从数据中学习空间结构而不是免费获得它.截至2026年,CNN仍然是许多中型和资源有限的视觉应用程序的更实用,更有效的数据选择,而视觉转换器 (和混合CNN转换器设计) 往往是最喜欢的最大规模视觉和多模系统,其中可获得巨大的训练数据集.
