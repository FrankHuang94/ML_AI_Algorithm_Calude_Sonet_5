## 线性回归

**名称和定义**线性回归预测连续数值输出作为输入特征的权重总和.

**起源.**最小方形的方法可以追溯到Legendre (1805) 和Gauss (1800年代初),远远早于计算是整个仓库中最古老的算法之一.

**核心机制.**ŷ = w1x1 + w2x2 + ... + wnxn + b,通过最大化MSE损失训练 (见[loss-functions.md](../01-foundations/loss-functions.md)根据""的定义,一个""的值可以在一个"的值之间进行计算.在这个简单的例子中,最佳权重可以在闭式形式 (通过线性代数来计算"正常方程") 而不是需要反复梯度下降,尽管在实践中使用梯度基调.通过:每个特征得到一个学习的系数,描述它如何推动预测上升或下降; b 是基线抵消.

**为什么这很重要.**它是最简单的模型,它捕捉到"从数据中学习权重来预测数量",它的假设 (线性,独立错误) 使得它对数学来说足够易于处理,

**现状.**实际上,在解释性问题或关系实际上接近线性 (或是被设计为线性) 时仍然是真正有用的;

**强度和局限性**
- 优势:可解释 (每个权重都有直接,可理解的意义),快速训练,不需要超参数调整,有充分理解的统计保障.
- 限制:不能在手动功能工程的情况下捕捉非线性关系;对异常值敏感 (由于二次错误损失);假设特性与彼此并不过于相关 (多线性扭曲了系数估计).

**与其他算法的关系.**逻辑回归是线性回归的分类对应 (下面);L1/L2处罚的线性回归成为LASSO/ridge回归 (见[regularization-techniques.md](../01-foundations/regularization-techniques.md)).

## 后勤回归

**名称和定义**逻辑回归是二进制 (或多类) 分类的线性模型:它预测了*概率*通过通过sigmoid函数传递线性特性组合的类型.

**起源.**后勤功能本身可以追溯到19世纪人口增长建模 (Verhulst, 1830年代至40年代);其作为统计分类模型的使用是在20世纪中叶正式化,并从1970年代至80年代成为标准统计和 ML工具.

**核心机制.**

```
p = σ(w·x + b) = 1 / (1 + e^−(w·x + b))
```

通过最小化二进制交叉缩损失训练. 通过: w·x + b 产生无限的真数 (a **位**尽管名称,逻辑回归是一种分类算法,而不是回归算法. 名称中的"回归"是从其统计起源起来的历史文物.

**为什么这很重要.**它是最简单的模型,将线性决策界限连接到正确校准的概率输出,并直接将其将化为几乎每个深度分类网络的最后层 (深度网的最后层通常只是对学习的非线性特征表示的物流/软高回归.

**现状.**广泛用于简单的分类任务,作为基线,以及在一个完整的神经网络是不必要的过head的延迟关键应用中;也几乎每个神经分类器的概念最终层.

**与其他算法的关系.**对于多类问题来说将其将于软max回归 (见 [loss-functions.md](../01-foundations/loss-functions.md));实际上,当你把深度学习视为学习的特征提取,然后是简单的线性分类器时,它是"神经网络的最后层".

## 决策树

**名称和定义**决策树通过询问有关输入特征的如果/然后问题,结构为二进制 (或多向) 树,在每个叶子上达到了预测的序列来预测出口.

**起源.**ID3 (Quinlan,1986),C4.5 (Quinlan,1993) 和CART (分类和回归树Breiman等,1984年) 是三个经典的树 induktion算法.

**核心机制.**树木是贪地建成的,从上到下:在每个节点上,算法考虑了每个特征和每个可能的分区点,并选择了最好的分区分数据到更纯的子组 (单类更主导的子组,用于分类,或较低的变异,用于回归).**标签:**其他**其他**使用**信息获取**(见缩量[loss-functions.md](../01-foundations/loss-functions.md)通过分开实现;**卡特**通常使用**基尼杂质**(如果根据子组的类分布随机标记一个被选中的元素的错误分类概率) 进行分类,或降低变异性进行回归.这个过程在每个结果子组上重复,直到满足停止标准 (最大深度,最小叶片大小,或没有进一步的改善).

通过:想象一下,你是否决定批准贷款,首先问"收入超过5万美元?"然后在每个分支提出一个问题,比如"信用评分超过700美元?"等等,直到你找到一个页面说"批准"或"拒绝".

**为什么这很重要.**树木产生了可以直接读取的人类的模型 (你可以字面上读取决策逻辑),并且不需要扩展特征或分布假设.

**现状.**现在,单一树很少用于单独生产中 (一个树往往过度适应,并且具有高差异性 训练数据中的小变化可以产生非常不同的树) 但它是统一方法 (随机森林,梯度增强) 的基本构建块[ensemble-methods.md](ensemble-methods.md).

**强度和局限性**
- 强度:可解释,可以以母语处理混合数量/类别特征,不需要扩展,可以自动捕捉非线性相互作用.
- 限制:过度适应 (足够深的树可以准确记住训练数据);不稳定 (小数据变化可能产生非常不同的树木);训练数据范围之外的外分差异.

## 支持向量机 (SVM)

**名称和定义** SVM 是一个分类器,它可以找到各类之间的决定边界,从而最大化边界与每个类的最接近训练示例之间的距离.

**起源.**科特斯和瓦普尼克"支持向量网络" (1995年),基于瓦普尼克和切尔沃伦基的早期边缘最大化理论,可追溯到1960-70年代.

**核心机制.**对于线性分离的数据,SVM发现了超平面w·x + b = 0 ,它最大化了两个类之间的边缘,通过最小化链损失训练 (见[loss-functions.md](../01-foundations/loss-functions.md)                              **支持向量**其他培训例都可以被删除,而不会改变所学到的边界.

**核的技巧 (概念).**实际数据通常在原始特征空间中无法线性分离.**核实技巧**通过SVM,可以有效地运行数据,就像数据已被转化为一个更高维度空间 (可能存在线性分离器) ,而从来没有明确计算这种转化.*点产品*转换点的组合之间,而不是转换点本身,并且内核函数可以直接和便宜地计算该点产品从原始 (未转换) 输入中.常见的内核包括多项内核和RBF (辐射基因函数或高斯) 内核,有效地衡量相似性作为距离的顺函数,并且可以代表极具灵活性,本地适应的决策界限.

**为什么这很重要.**在深度学习的起之前,SVM (特别是RBF内核) 通常是可用于广泛的中小至中小,中度高维度数据集的最佳分类器,边缘最大化框架为该领域提供了较强的通用化保证,在早期的ML方法中更少.

**现状.**现在的位被梯度增强的树木所取代,[ensemble-methods.md](ensemble-methods.md)仍在一些较小数据或高维度但有限的样本科学和生物信息学环境中使用,其中其通用性仍然具有吸引力.

**强度和局限性**
- 强大:强大的理论概括保障;高维空间有效;内核技巧允许灵活的非线性界限,而无需明确的特征工程.
- 限制:不适用于非常大的数据集 (在示例数量中,天真训练大约是平方立方);内核选择和超参数 (如规则化强度和内核特定参数) 需要调整;比树木或线性模型更难解释;没有自然概率输出 (概率估计需要额外的校准步骤).

## k-近邻 (k-NN)

**名称和定义**k-NN通过查看培训集中的 k 最接近点,并通过多数投票 (分类) 或平均 (回归) 来分类 (或预测一个值).

**起源.**固定和霍奇斯 (1951,技术报告),后来由Cover和哈特正式化,"近邻模式分类" (1967).

**核心机制.**没有训练阶段在通常意义上  k-NN 只是存储整个训练集 ("惰学习"或"实例学习").在预测时间,它计算了查询点到每个训练点的距离 (通常是尤克利德式),找到最接近的 k,并汇总了它们的标签.

**为什么这很重要.**它是最简单的非参数方法 (没有假设输入和输出之间的关系的功能形式) 而且仍然是一个有用的概念基线: "最简单的基于相似性的预测将是什么样子?"

**现状.**很少是今天高维度或大规模问题的最佳选择 (距离指标在高维度中变得不那么有意义"维度诅咒",在推理时存储/搜索完整的培训集是昂贵的),但底层的"寻找类似的例子"想法在现代的检索增强系统中非常活跃,并且在嵌入式中近乎接近邻居搜索.

**强度和局限性**
- 强大:不需要培训;简单,直观;自然处理多类问题.
- 限制:在大型数据集中推理时间缓慢 (天真搜索是数据集尺寸线性的,尽管近似方法可以减轻这一点);高维空间中的性能下降;对无关/未扩展的特性以及选择k和距离指标的敏感性.
