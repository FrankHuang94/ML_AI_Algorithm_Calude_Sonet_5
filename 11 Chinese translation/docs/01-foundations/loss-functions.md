# 损失函数

损失函数是模型经过训练以最小化的单个数字 - 它量化模型当前预测的“错误程度”，对训练示例进行平均，以便 [optimization-algorithms.md](optimization-algorithms.md) 中的优化算法有一些具体的需要减少的东西。损失函数的选择决定了对于给定任务来说“良好性能”意味着什么，因此正确（或错误）会影响下游的一切。该文件还简要介绍了**熵**和**KL散度**，这些基本信息论概念在该仓库的其他地方不断重复出现。

损失函数最有用的内部化是它们的“形状”——它们惩罚一定数量的错误的力度有多大——因为这种形状正是优化器所追求的。以下是主要的回归/分类损失，概述为“惩罚与预测的错误程度”：

```
MSE (squared)        MAE (absolute)       Cross-entropy            Hinge (SVM)
penalty                penalty              penalty                  penalty
│   .                  │  \   /             │ \                      │\
│    .       .         │   \ /              │  \                     │ \
│     .     .          │    V               │   \__                  │  \___________
│      \   /           │   / \              │      ‾‾‾‾--__          │       margin↑
└────────V────► err    └──/───\──► err      └───────────► p(correct) └──────────► y·f(x)
big miss = HUGE      big miss grows       confident-wrong          zero penalty once
(parabola)           only linearly        → ∞; confident-right     safely correct past
→ 0                      the margin
```

从每个形状中读出设计意图：MSE 的抛物线意味着一个大的异常值主导了损失（因此模型向后弯曲以修复罕见的巨大错误）； MAE的“V”按比例对待大失误，因此它更多地忽略异常值；交叉熵的爆炸墙几乎无限制地惩罚*自信的错误*答案；一旦您安全正确，铰链就会变平，因此一旦满足裕度，它就不再关心。该文件的其余部分主要是这四种形状加上一些特殊的变体。

## MSE / L2 损失

**定义。** 均方误差对预测值和真实值之间的平方差进行平均。

```
L = (1/N) · Σᵢ (yᵢ − ŷᵢ)²
```

演练：对于每个示例 i，取真实值 yᵢ 和预测 ŷᵢ 之间的差值，对其进行平方（因此任一方向的误差都算作正数，较大的误差比小误差受到的惩罚不成比例），然后对所有 N 个示例进行平均。平方意味着单个大的失误所受到的惩罚比相同总规模的几个小失误受到的惩罚要严重得多——MSE 对异常值很敏感。

**使用地点。** 回归任务（预测连续数）的标准损失 - 房价预测、预测以及某些图像模型中的每像素重建损失。作为分类或语言建模的主要损失很少见。

## MAE / L1 损失

**定义。** 平均绝对误差对预测值和真实值之间的绝对（非平方）差进行平均：L = (1/N)·Σᵢ|yᵢ − ŷᵢ|。

**为什么它与 MSE 不同。** 因为误差不是平方的，所以 MAE 会按其大小而不是其平方来惩罚较大的单个误差 - 它对离群值的敏感度远不如 MSE，代价是接近零误差的平滑梯度较差（其导数是一个常数 ±1，无论误差大小如何，而不是与误差成正比）。当对异常值的稳健性比严重惩罚重大失误更重要时使用。

**Huber 损失** 是两者之间的实际折衷：对于小误差，它的行为类似于 MSE（平滑抛物线）；对于大误差，它的行为类似于 MAE（线性），以可调阈值 δ 进行切换。这为您提供了 MSE 接近最佳值的平滑梯度*和 MAE 对偶尔出现的巨大异常值的鲁棒性。这是鲁棒回归的常见默认值，并出现在强化学习中——DQN 系列（参见 [value-based-methods.md](../07-reinforcement-learning/value-based-methods.md)）通常在其值预测误差上使用 Huber 损失，正是因为 RL 目标有时可能会严重偏离，并且您不希望这样的目标产生不稳定的梯度。

## 交叉熵损失

**定义。** 交叉熵损失衡量预测概率分布与真实（目标）分布之间的差异，是分类的标准损失。

**背景：熵。** 在交叉熵有意义之前，用一句话来掌握信息论中的 **熵** 会有所帮助：熵衡量概率分布中固有的不确定性（或者等效地，有多少信息位）。一枚总是正面朝上的硬币的熵为零（没有不确定性——你总是知道结果）；一枚公平的硬币对于两种结果分布具有最大熵（你从观察每次翻转中学到最多，因为你事先有最大的不确定性）。形式上，熵 H(p) = −Σₓ p(x)·log(p(x))。

**二元交叉熵**（两类，例如“垃圾邮件”与“非垃圾邮件”）：

```
L = −(1/N) · Σᵢ [yᵢ·log(ŷᵢ) + (1 − yᵢ)·log(1 − ŷᵢ)]
```

其中 yᵢ ∈ {0, 1} 是真实标签，ŷᵢ ε (0, 1) 是模型的第 1 类预测概率。演练：对于每个示例，根据真实标签，只有两项是“活跃”的（如果 yᵢ = 1，则第二项消失；如果 yᵢ = 0，则第一项消失）——损失就是 −log（正确类别的预测概率）。由于接近 1 的数字的对数接近 0，而接近 0 的数字的对数接近负无穷大，因此当模型自信地预测正确答案时，这种损失接近于零，并且当模型自信地预测“错误”答案时，这种损失会呈爆炸式增长。对自信错误的不对称、无限制的惩罚是一个故意的设计特征：它积极地惩罚过度自信的错误。

**分类交叉熵**（超过两个类）使用 **softmax 函数**对此进行概括，该函数将原始分数向量 (**logits**) 转换为有效的概率分布（所有值均为正，总和为 1）：

```
softmax(zᵢ) = e^zᵢ / Σⱼ e^zⱼ
L = −(1/N) · Σᵢ log(ŷᵢ,correct_class)
```

演练：softmax对每个 logit 求幂（使所有内容都为正值并夸大大分数和小分数之间的差距）并按总和进行归一化，为每个类别生成一个概率。那么，损失只是模型分配给正确类别的概率的负对数 - 与二元情况相同的“自信正确，接近零损失；自信错误，巨大损失”形状，推广到许多类别。

**一个具体的示例，因此“爆炸”声明不是抽象的。** 假设正确的类是“cat”，我们查看单个示例的损失（自然对数），因为模型对“cat”的置信度不同：

|模型在正确类别上的概率 |损失 = −ln(p) |
|---|---|
| 0.99（非常有信心，正确）| 0.01 | 0.01
| 0.70（相当有信心，正确）| 0.36 | 0.36
| 0.50（不确定）| 0.69 | 0.69
| 0.10（肯定是错误的）| 2.30 | 2.30
| 0.01（非常自信地错误）| 4.61 | 4.61

请注意这种不对称性：正确几乎不会增加损失（0.01），但自信错误会受到严厉惩罚（4.61），并且惩罚没有上限——将接近 0 的概率分配给真实答案的模型会导致接近无穷大的损失。这正是概率分类器想要的属性：它使模型为自信的错误付出高昂的代价，从而推动模型进行“校准”（诚实地对待其不确定性），而不是鲁莽地过度自信。

**为什么重要/当前状态。** 交叉熵基本上是所有分类任务的默认损失，并且（对于此仓库至关重要）它也是用于训练下一个标记预测的语言模型的损失（预测下一个标记是词汇表的分类问题；请参阅 [autoregressive-generation.md](../04-generative-models/autoregressive-generation.md)）。截至 2026 年，它仍然完全占主导地位。

## 铰链损失 (SVM)

**定义。** 铰链损失是用于训练支持向量机的损失函数（参见 [supervised-learning.md](../02-classical-ml/supervised-learning.md)）：L = max(0, 1 − y·f(x))，其中 y ∈ {−1, +1} 是真实标签，f(x) 是模型的原始（无界）输出分数。

演练：如果模型的预测具有正确的符号 *并且* 自信地超过 1 的裕度（即 y·f(x) ≥ 1），则损失恰好为零 - 更加自信不会有进一步的奖励。如果预测在裕度范围内或错误，则损失会线性增长。这种“一旦安全正确就平坦”的形状与交叉熵不同，交叉熵会无限期地奖励置信度——它直接编码 SVM 的“最大余量”目标（找到一个在类之间尽可能分离的决策边界，一旦实现就不必再进一步优化）。

**当前状态。** 经典 SVM 故事的核心；如今很少用于训练深度网络，其中交叉熵在分类中占主导地位。

## KL 散度

**定义。** Kullback-Leibler (KL) 散度衡量一个概率分布与另一个概率分布的差异程度 - 具体来说，使用分布 Q 来描述实际来自分布 P 的数据会产生多少“额外的惊喜”。

```
D_KL(P ‖ Q) = Σₓ P(x) · log(P(x) / Q(x))
```

演练：对于每个可能的结果 x，根据该结果实际处于真实分布 P 下的可能性来加权两个分布概率的对数比。如果 P 和 Q 相同，则每个对数比项为 log(1) = 0，因此 KL 散度恰好为零。 Q 的概率与 P 的概率差异越大（特别是通过将低概率分配给 P 认为可能的结果），值就越大。 KL 散度**不对称** — 一般而言，D_KL(P‖Q) ≠ D_KL(Q‖P) — 这在选择哪个分布是“参考”(P) 以及哪个分布是拟合分布 (Q) 时很重要。

**为什么不对称性实际上很重要——模式覆盖与模式寻求。**这不仅仅是数学上的迂腐；它是一种数学上的学问。当您将简单模型 Q 拟合到复杂的真实分布 P 时，这两个方向会产生明显不同的行为，并且它解释了生成模型中的实际设计选择。 **前向 KL**，D_KL(P‖Q)，由 P 较大的地方主导——它会严重惩罚 Q，因为它为实际上常见的结果分配低概率，因此最小化前向 KL 的 Q 是“模式覆盖”：它会自行扩展，在 P 所做的任何地方至少放置一些概率，即使这意味着在多个不同模式之间进行模糊（这大致就是最大似然训练，因此是交叉熵的作用 - 见下文）。 **反向 KL**，D_KL(Q‖P)，由 Q 大的地方主导 - 它惩罚 Q 将概率放在 P 小的地方，因此 Q 最小化反向 KL 是“模式寻求”：它更喜欢锁定 P 的一种模式并忽略其他模式，而不是在它们之间模糊。当您后来读到 VAE（参见 [vaes.md](../04-generative-models/vaes.md)）或某些 RL 目标使用一个方向或另一个方向时，这就是危险的行为后果——“我是希望模型对冲并覆盖所有内容，还是致力于一个看似合理的答案？”

**为什么这个问题在这个仓库的其他地方如此频繁地出现。** KL散度反复出现：作为VAE的ELBO目标中的正则化项（参见[vaes.md](../04-generative-models/vaes.md)），作为TRPO中的约束和PPO中的隐式约束（参见[policy-gradient-methods.md](../07-reinforcement-learning/policy-gradient-methods.md)），以及作为保持RLHF 调整模型的输出偏离预训练基础模型太远（参见 [rlhf-and-alignment.md](../05-training-methodology/rlhf-and-alignment.md)）。值得在这里内化一次，而不是在每个文件中重新推导：KL 散度是惩罚“分布 Q 与参考分布 P 偏离太远”的标准方法。

**与交叉熵的关系。** 交叉熵 H(P, Q) = H(P) + D_KL(P‖Q) — 交叉熵是真实分布的熵加上真实分布和预测之间的 KL 散度。由于 H(P) 是固定的（它不依赖于模型），因此最小化模型预测的交叉熵在数学上相当于最小化真实分布和预测分布之间的 KL 散度。这就是为什么交叉熵损失可以理解为“直接惩罚错误的预测”或“使预测的分布尽可能匹配真实的分布”——它们是相同的目标。

## 对比损失：InfoNCE 和三元组损失

**定义。** 对比损失训练模型生成表示（**嵌入** - 表示学习空间中的输入的密集数值向量，其中几何距离对应于语义相似性），对于“相似”的输入对来说，这些表示距离很近，对于“不相似”的输入对来说，这些表示相距很远，而不是直接预测标签。

**Triplet loss** (Schroff et al., 2015, FaceNet) 采用一个锚点示例、一个正例（与锚点相同的类）和一个负例（不同类），将锚点-正距离向下推，同时将锚点-负距离向上推，边距：L = max(0, d(anchor, Positive) − d(anchor, negative) + margin)。

**InfoNCE**（van den Oord 等人，2018 年，在对比预测编码的背景下）将这一点同时推广到许多负数，使用一个类似于 softmax 的公式针对一个正对对一批负对：

```
L = −log[ exp(sim(a, p)/τ) / Σⱼ exp(sim(a, nⱼ)/τ) ]
```

其中 sim 是一个相似度函数（通常是余弦相似度），τ (tau) 是一个温度参数，控制 softmax 区分紧密调用的清晰度。演练：这正是分类交叉熵公式，但将“类”替换为“这些候选示例中哪一个是真正的匹配”——模型的训练就像解决多项选择问题一样，其中正确答案是真正的正对，干扰项是批次中的负数。

**现在使用的地方。** InfoNCE 风格的对比损失是 CLIP 风格图像文本对齐背后的训练目标（参见 [pretraining-strategies.md](../05-training-methodology/pretraining-strategies.md)）和许多用于搜索和检索的现代嵌入模型。

## 焦点损失

**定义。** 焦点损失是针对严重类别不平衡而设计的交叉熵的修改（当训练数据中一个类别的数量远远超过另一个类别时，例如，在对象检测中，“背景，这里没有对象”的数量远远超过“存在对象”的数量）。

**起源。** Lin 等人，“密集物体检测的焦点损失”（2017 年，与 RetinaNet 检测器一起推出）。

**核心机制。** 焦点损失将标准交叉熵项乘以一个因子，该因子可以降低简单的、已经很好分类的示例的权重：L = −(1 − ŷ)^γ · log(ŷ)，其中 ŷ 是真实类别的预测概率，γ（伽玛，通常约为 2）控制如何积极地降低简单示例的权重。

演练：当 ŷ 已经接近 1（一个简单、正确分类的示例）时，(1 − ŷ)^γ 接近于 0，因此该示例对损失几乎没有任何贡献，即使标准交叉熵仍会为其分配一些（小）损失。这会将训练信号重定向到实际需要的更难、错误分类或少数类示例，从而防止大量简单的多数类示例淹没罕见但重要的学习信号。

**当前状态。** 具有严重前景/背景不平衡的对象检测管道的标准；其他地方不太需要。

## 困惑度

**定义。** 困惑度是以更易于人类解释的形式报告语言模型交叉熵损失的标准方法：困惑度 = e^(交叉熵损失)（使用交叉熵的自然对数版本）。

演练：语言模型的交叉熵损失以每个标记的“nats”（或位，如果使用对数基数 2）来衡量——这是一个很难建立直觉的抽象单位。困惑将其转化为“平均而言，模型的不确定性就像它在这么多同样可能的下一个标记中统一选择一样”。困惑度为 1 意味着模型完全确定每个下一个标记（在实际语言中这是不可能的）；例如，困惑度为 20 意味着模型对下一个标记的平均不确定性相当于在每一步中从 20 个选项中均匀选择。在其他条件相同的情况下，较低的困惑度意味着更适合的语言模型。

**当前状态。** 仍然被广泛报道为语言模型质量指标，尽管该领域越来越多地用下游任务基准和人类/模型判断的评估来补充（并在许多目的上取代）困惑度，因为低困惑度并不自动意味着模型擅长遵循指令、推理或用户关心的特定行为。

## 汇总表

|损失|任务类型 |对异常值敏感？ |典型用途|
|---|---|---|---|
| MSE / L2 |回归|是（误差平方）|连续值预测 |
| MAE / L1 |回归|没有 |稳健回归|
|胡贝尔 |回归|减少（MSE→MAE 超过阈值 δ）|鲁棒回归，RL 值目标 (DQN) |
|二元/分类交叉熵 |分类|不适用（基于概率）|分类、语言建模|
|铰链损失|分类（基于保证金）|中等|支持向量机 |
| KL 散度 |分销配套|不适用 | VAE、RLHF/PPO 漂移约束、蒸馏 |
| InfoNCE / 三元组损失 |表征学习 |不适用 |嵌入、对比预训练（例如 CLIP）|
|焦点丧失 |分类（不平衡）|通过设计减轻简单示例的重量 |物体检测|
