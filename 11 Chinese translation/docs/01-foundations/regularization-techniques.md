## L1/L2规律化和体重衰减

**定义.**L1和L2规律化增加了根据模型权重大小的损失函数的罚款期限,从而阻止模型依赖非常大的权重值.

**起源.**两者都是经典的统计数据 (L2  Hoerl 和 Kennard 的回归,1970年;L1  Tibshirani 的 LASSO,1996年),基本上没有改变.

**核心机制.**

```
L2:  Loss_total = Loss_original + λ · Σ θᵢ²
L1:  Loss_total = Loss_original + λ · Σ |θᵢ|
```

通过:你不再仅仅减少预测错误 你正在减少预测错误*另外*由于Sθi2的梯度与 θi相对是 2θi,因此L2规则对梯度的影响是减去一个与体重本身相比例的术语每一步,这将每个体重稍微接近零,每一步,相对其当前大小.L1的梯度 (与标志相比例),即不论大小的恒定拉力,往往会推小权重到完全零,这使L1用于生产稀疏模型 (许多权重为零) ,这是一种特征,偶尔用于经典 ML中特征选择,较少用于深度学习.

**减肥的差别.**在简单的SGD中,加上L2规律化到损失的数学上与称为"体重衰减" (每次更新每次减重一个常数因素) 的单独步骤相同.[optimization-algorithms.md](optimization-algorithms.md)在亚当这样的适应优化器下,这种等效性会破裂:将L2罚款折叠成梯度,**亚当W**通过将其应用为单独的操作,而不是适应梯度步骤.这就是为什么现代论文谨慎区分"L2规范化" (损失函数级罚款) 和"体重衰减" (参数的直接,不扩展缩小).

**现状.**传统L1/L2-as-loss-penalty仍然被教导和使用在经典ML (见[supervised-learning.md](../02-classical-ml/supervised-learning.md)) 但与下列技术相比,它是深度学习的二级调节剂.

## 放弃和放弃Connect

**定义.**降落在每一步训练中随机排放 (降落) 一部分层的激活,迫使网络不过依赖任何单个神经元.

**起源.**斯里瓦斯塔瓦,希顿等, "Dropout:一个简单的方法来防止神经网络过度适应" (2014,后于2012年预印).

**核心机制.**在训练期间,每个神经元的输出独立以概率p (通常是0.1-0.5) 进行零化,生存的激活被扩大到1/(1−p) 保持预期总大小不变.在推理 (测试) 时间,中断完全关闭所有神经元都活跃,并且没有需要扩展,因为训练时间扩展已经占据了这一点.

通过:由于任何特定神经元可能在任何训练步骤上消失,任何其他神经元都无法承受与它太紧密的协同适应 (即,只能与特定的其他神经元结合正常工作的脆弱依赖性).这迫使网络开发更冗余的,个别有用的表示,这往往更好地通用. 脱落也可以理解为训练大量"薄"子网络的隐含组 (每个脱落面具定义了不同的子网络) 的预测在测试时被隐含平均.

**为什么这很重要.**放弃是2012-2017年深度学习时代最有效和广泛采用的调节剂之一,并且是减少该时期大型完全连接和卷积网络过度适应的关键成分.

**连接**和的变体.*体重*更细细的版本,不太常用于标准的废弃.

**现状.**仍然在一些架构中使用 (通常在经典/较小的网络中),但现代大型Transformer预训练通常使用很大规模的缩小率很少或没有缩,数据集远远大于模型的记忆能力,过度适应较于较小的模型而不是较小的数据集训练的第一级问题,而缩的缩性可以稍慢缓和,这在训练运行成本数百万美元时很重要.缩仍然是细调阶段和较小的模型中常见的.

## 批量正常化,层正常化,RMSNorm

由于它们解决相关问题,因此它们组合在一起, 保持通过深层网络流动的激活的规模良好, 但在不同的轴上应用了固定,并在不同的架构中占主导地位.

### 批量正常化 (批量规范)

**起源.**伊夫和谢格迪, "批量正常化:通过减少内部变量变化加速深度网络培训" (2015).

**核心机制.**对于每次激活,BatchNorm将其正常化 (减去平均值,以标准偏差划分)*在当前的小批量中*网络可以取消正常化,如果这对给定的层来说实际上更好:

```
x̂ = (x − μ_batch) / √(σ²_batch + ε)
y = γ·x̂ + β
```

通过:随着数据流动在深层网络中,每个层次的激活的分布随着早期层次的权重变化而在训练中可能会转移 (原稿称之为"内部变量转移",尽管后来的工作已经辩论了这是否是BatchNorm的好处背后的机制).BatchNorm在每个层次的激活重新中心和重新扩展,这对训练进行实验性稳定和加速,并允许您使用更高的学习率安全.

**为什么这很重要.**轮轮网络是2010年代中期非常深层次的训练 (见[cnn-family.md](../03-deep-learning-architectures/cnn-family.md)如果没有ResNet这样的网络,训练将要比训练更难.

**限制.**批量Norm的统计数据取决于迷你批量,这导致了小批量尺寸 (噪音统计) 和序列模型的问题,其中批量组成和序列长度不同,

### 层正常化 (LayerNorm)

**起源.**,基罗斯,希顿,"层正常化" (2016).

**核心机制.**层规范在整个批量维度中正常化,*功能*尺寸,独立于每个个体例子:

```
x̂ = (x − μ_features) / √(σ²_features + ε)
y = γ·x̂ + β
```

通过:每个单个训练示例的激活向量仅使用其自己的值重新中心化和重新扩展,而不是从批量中的其他示例中借来的统计数据.这使得LayerNorm的行为在训练和推理时间上相同 (没有批量依赖的统计数据可担心) 并独立于批量大小或序列长度,这是Transformer处理变量长度序列时需要的特征.

**为什么这很重要.**在各个位置见LN前与LN后的讨论[transformer-architecture.md](../03-deep-learning-architectures/transformer-architecture.md)) 是原始Transformer中使用的正常化方案,并且自此以来,大多数基于Transformer的 LLM中使用.

### 标准

**起源.**张和森里希, "根中方层正常化" (2019).

**核心机制.**RMSNorm通过完全放下中中心步骤并仅通过激活的根-中方方位重新扩展简化了LayerNorm:

```
x̂ = x / √(mean(x²) + ε)
y = γ·x̂
```

通过:作者发现LayerNorm的重中心化 (减去平均值) 对其益处贡献很少.大部分价值来自重缩.放弃平均计算 (和学习的转移β) 节省了计算和内存,几乎没有质量损失.

**现状.**截至2026年,RMSNorm已成为大多数现代大型语言模型 (包括LLaMA-家庭和其他许多语言) 的默认正常化层,由于其成本较低,并具有同等质量,在新的架构中取代了标准LayerNorm.

### 群体正常化和每个标准的存在点

**群体正常化 (群体规范)**(Wu and He, 2018) 位于BatchNorm和LayerNorm之间:它将一个层的道分成组,并在每个组内正常化,例如,所以,就像LayerNorm一样,它不取决于批量 (解决BatchNorm的小批量问题),但它在一个中正常化*组件*它们是最重要的,因为它们通常在U-Net的部中使用的标准化 (见[diffusion-models.md](../04-generative-models/diffusion-models.md)), 批量可能很小,而BatchNorm的批量依赖不必要.

它们的唯一不同是*哪些轴*平均值为计算平均值/变量.BatchNorm对每个频道的批量 (和空间) 轴进行平均值;LayerNorm对每个例子的所有特性进行平均值;GroupNorm对每个例子的组特征进行平均值;RMSNorm是 LayerNorm,没有平均减小.相同的操作,不同的数据片.

**现在,我们需要一个新的方法.**值得标记为2026年参考的一项更近期发展:现在几台大型转变器直接将正常化应用到查询和注意力内部的关键向量 (见[transformer-architecture.md](../03-deep-learning-architectures/transformer-architecture.md)"QK-norm".它的目的是在大型训练中保持注意力记录 (原料前软max分数) 从增加到极端大小,这导致了训练不稳定性 ("损失峰值") 在非常大的模型中.它不如训练稳定机制一般化调节剂,但它生活在"正常化激活保持训练良好行为"技巧的同一家中,这就是为什么它属于上面的标准.

## 提前停车

**定义.**早期停止停止训练,一旦在一个持久的验证集中的性能 (数据除了训练,仅用于监测通用化) 停止改善,而不是训练一个固定的,预先确定的步骤数量.

**为什么这很重要.**随着训练的持续下降,训练损失不断下降,但在模型开始过度匹配后,验证损失通常再次开始增加. 早期停止捕获了转折点并保持了检查点就在前面. 这是一种几乎免费的调节剂 (仅仅需要计算定期验证检查),并且仍然是整个领域的标准做法,从经典的 ML 到 LLM预训练 (在此,它更常以"通过验证损失来停止和选择最佳检查点"的形式而不是一个硬自动触发器).

## 数据增强

**定义.**通过将标签保存的转型应用到现有例子,数据增强将人工扩大培训集的实际规模和多样性.

**经典的例子**,任何一个都不应该改变图像中的内容 (一张被翻过的照片仍然是猫),所以标签保持不变,而模型看到更多的多样性.

**现代的例子**: **混合物**通过线性地混合两个图像及其标签 (例如,70%的猫图像 +30%的狗图像,标签是70%的猫 /30%的狗);**切合**(Yun et al., 2019) 相反,将一个矩形补丁从一个图像粘贴到另一个图像,并与补丁区域相对比例地混合标签.这两者都鼓励模型在训练示例之间 (更柔软的决策界限) 进行更线性行为,而不是记住尖的,具体的示例模式.对于文本,常见的方法包括后翻译 (翻译到另一个语言和回来获得抛词) 和越来越多的其他模型生成的合成数据 (见 图文)[curriculum-and-data-strategies.md](../05-training-methodology/curriculum-and-data-strategies.md)).

**现状.**视觉特征增强仍然是计算机视觉管道中的标准;混合/切割混合式技术用于特定视觉训练配方,但并不普遍.对于大型语言模型预训,基于合成数据的方法已成为比经典增强更为核心.

## 标签滑滑

**定义.**标签平滑取代"硬"单热分类目标 (100%的可能性在正确类别上,其他地方是0%) 的"软"目标 (例如,在正确类别上是90%的目标,剩余的10%分布在其他类别上).

**起源.**引入了Inception架构 (Szegedy等人, 2016).

**为什么这很重要.**培训模型到输出*确切地*对于正确答案的100%信心,**子**一个分类器在转换为概率之前产生的非正常分数,通常通过软max函数;见[loss-functions.md](loss-functions.md)标签平滑帽表现出模型的信心程度,这可以作为一个轻微的调节剂,并且往往改善了校准.

## 剩余/跳转连接作为隐含的规律化

**定义.**剩余 (或"跳") 连接将一个层的输入直接添加到其输出,所以该层只需要学习*差异*"剩余"是输入和所需输出之间的,而不是从零开始的整体转换.

**为什么这算是规律化.**除了它们的主要,在使更深层次的网络能够完全训练之外,[cnn-family.md](../03-deep-learning-architectures/cnn-family.md)),跳转连接具有二次规律化效果:它们给梯度一个直接,无障碍的路径回网络 (一个"身份快捷方式"),并且让网络默认学习某个特定区块的身份函数附近的东西,如果该区块没有提供有用的转型.

**底**技术的发展,*随机抛出整个残留块*类似于放弃,但在整个层而不是单个神经元的水平上,它既规范化,也加快了非常深层网络的训练,并且用于一些视觉架构.

## 隐含的规律化:你得到的规律化剂是免费的

许多标准训练选择是正常化作为副作用,这值得明确地命名,因为它解释了为什么大型车型经常过度适应*减少*简单的参数数数量预测的比较:

- **警方本身的噪音.**微批次梯度估计的随机性 (见 [optimization-algorithms.md](optimization-algorithms.md)每一步都使用了对真梯度的噪音估计而不是确切的估计. 这不是纯粹的麻烦.这种噪音实验上推动了训练,以损失景观的"平坦"区域 (如果参数稍微受到破坏,损失不会急剧改变的最小),而平坦的最小则往往比尖的更好.这是为什么较小批量有时比非常大的批量更好地普遍的解释.
- **终止训练/提前停止.**只是没有向向的训练本身就是规范化,
- **精度有限.**培训较低的数值精度 (见[quantization.md](../06-inference-optimization/quantization.md)) 射少量的圆噪音,可产生轻微的调节效果.

实际结果:当你读到现代的LLM使用"少或没有放弃",这并不意味着它是不规范的. 意思是结合巨大的,多元化的数据集 (所以首先需要记住的训练集的噪音),
