# 精细调节和参数效率精细调节

调整调整适应预训练模型 (见 [pretraining-strategies.md](pretraining-strategies.md)通过使用比预训使用的更小,更有针对性的数据集,将其用于特定任务,域或行为. 这文件涵盖了完全的细节调整,为什么在LLM规模上变得不实用,以及解决这种不实用性的参数效率细节调整 (PEFT) 方法.

## 完全调整

**名称和定义**完全细调更新了预训练模型的每个参数,使用与预训练相同的梯度培训 (见[optimization-algorithms.md](../01-foundations/optimization-algorithms.md)),只用较小的,具体任务的数据集,通常是少得多的步骤.

**为什么它能有效.**一个预训练模型已经从预训练中得到了好的一般表现;细调将这些表现和模型的输出行为推向一个特定的任务,而不需要从零开始重新学习一切,因为预训练的权重比随机初始化更好的起点.

**为什么在法学士级别上变得不实用.**完全调整需要存储和更新梯度和优化器状态 (从[optimization-algorithms.md](../01-foundations/optimization-algorithms.md)对于 的每个参数,*每一个*对于一个拥有数十亿或数十亿参数的模型,这意味着调整所需的内存是模型本身的大小的多倍,通常使得完全调整在不仅仅是用于预训练的相同的大规模硬件集群上是不可能的.这也意味着如果你想要相同的基础模型的许多不同的调整变体 (例如,每个客户或每个任务),你需要为每个变体存储整个模型的权重的完全单独副本.

## 参数效率细调的动机

**核心想法.**代替更新模型的所有参数,完全结预训练的权重,并训练只有一小部分额外或修改的参数训练的记忆足迹更小, (关键) 每个细调的"变量"都可以被表示为只是那一组额外参数,层次叠加在一个共享的,结的原型副本上,而不是需要自己的完整的模型副本.

## 低级调整 (LoRA)

**起源.**胡等人 (微软),"LoRA:大语言模型的低级适应" (2021).

**核心机制 低级分解,清楚解释.**在预训练模型中给定的权重矩阵W (例如,在注意或输送层内的一个d×d矩阵),LoRA完全结W,而不是学习添加更新 ΔW,但限制 ΔW作为两个更小的矩阵的产量表达:

```
ΔW = B · A         where B is d×r, A is r×d, and r ≪ d
h = W·x + ΔW·x = W·x + B·(A·x)
```

```
   Full fine-tuning: update the whole      LoRA: freeze W, learn a thin B·A instead
   d×d matrix (d² parameters)              (2·d·r parameters, r ≪ d)

        ┌───────────────┐                     ┌───────────────┐    ┌─┐
        │               │                     │               │    │ │ B  (d×r,
        │   W  (train    │                     │   W  (FROZEN) │  + │ │     tall & thin)
        │   all of it)   │                     │               │    │ │
        │               │                     │               │    └─┘
        └───────────────┘                     └───────────────┘    ┌──────┐
         d² numbers to learn                  0 new here            └──────┘ A (r×d, short & wide)
         (e.g. 4096×4096                                            2·d·r numbers
          ≈ 16.7M per matrix)                                       (e.g. 4096×8×2 ≈ 66K — ~250× fewer)
```

通过:而不是学习一个完整的d×d更新矩阵 (可能具有d2参数),LoRA学习了两个更薄的矩阵A和B,其产品接近更新 这只有2·d·r参数,其中r (分解的"级别"通常是4,8或16这样的小数字,而d值可能在数千中) 被选为远小于d.图中的数字使得节省生动:对于4096×4096矩阵,完整的细调学习~士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士号,士士士,士士士士~为每矩阵大约250倍少. 这就是名字中的"低级"*有用*更新一个预训练的权重矩阵对给定的任务不需要探索可能的d×d变化的全部空间,但可以通过一个更低的维度 (rank-r) 更新来很好地接近.在推理时,B·A甚至可以计算一次并直接添加到W,这意味着一个LoRA适应的模型可以与原始模型相比运行零额外延迟,如果需要,可以单独保持或B·A并交换每个任务/客户,同时使用相同的结基重 W为许多不同的LoRA适配器.

**为什么这很重要.**LoRA将可训练的参数数 (以及它们所需的优化器状态) 减少到与完全细调相比大小数量,通常低于基本模型参数数数量的1%,同时在广泛的设置中实验性地匹配完整细调的任务性能.这使得细调的大型模型在更少的硬件上具有实用性,并且使得保持许多不同的任务/客户特定细调便宜 (因为在一个共享的基本模型上层次的小型LoRA适配器文件) 而不是许多完整模型副本.

## 定量化+定量化

**起源.**德特默斯等人",QLoRA:量化LLM的有效细节调整" (2023).

**核心机制.**QLoRA将LoRA与量化结合在一起 (使用低精度数量格式表示冷基模型的权重见[quantization.md](../06-inference-optimization/quantization.md)对于完整的机械学 (通常在QLoRA的情况下是4位精确的) 冷基权重在细调过程中存储和使用在量化 (压缩) 形式,而小的LoRA适配矩阵A和B仍然在正常的更高精度中训练.该论文还引入了支持技术 (一个特定的4位数据类型为典型的神经网络权重分布调整,并谨慎管理优化状态的内存) 保持这种组合数量稳定,尽管冷基模型的侵略压缩.

**为什么这很重要.**通过量化 (更大的) 结基模型,同时保持 (更小的) 可训练的LoRA参数的完全精度,QLoRA削减了对细调大型模型所需的内存,甚至远远超过LoRA.

### 较广泛的LoRA家族 (DoRA和其他精炼)

洛拉已经产生了一系列值得注意的改进,**子**(权重分解低级调整,2024) 将每个权重分为一个大小和一个方向,并仅对方向进行LoRA类型的低级调整,该调整将LoRA和完全细调之间的残余精度差距缩小,以类似的参数成本.*在哪里*排名被花费 (将更多的排名分配给需要的层次) 或*如何*读者所需要的实际结论:LoRA不是单一的结技术,而是一个积极精炼的家族,而"使用LoRA"在2026年通常意味着"使用LoRA或其近代之一",原始的原始仍然是完全强大的默认.

## 适配器

**名称和定义**适配器直接将新启动的小神经网络层 (通常是一个瓶:下调到小维度,应用非线性,上调) 插入到冷预训练模型的架构中.

**起源.**霍尔斯比等人",NLP的参数效率转移学习" (2019) 是LoRA之前的,也是变体器最早的PEFT方法之一.

**交易与洛拉相比.**适配器在推理时添加额外的序列计算 (数据必须通过新的瓶层,与LoRA的更新不同,可以直接融入现有权重矩阵,而没有添加推理时间计算),这是LoRA风格方法变得更受欢迎的原因,即使适配器仍然是一个合理的,既定的PEFT选择.

## 预写调整和快速调整

**预写调整**(Li,Liang,2021) 预先将学习的连续 ("软") 矢量序列为模型的每个层输入 (不是实际的词可训练的矢量,这些矢量不与任何实际词元相符),训练只有这些预先向量,同时保持模型的其余部分结;模型以这些学习的预先为额外的语境来指导其行为向精细调的任务.

**快速调整**(莱斯特,阿尔-鲁福,常态,2021) 是一个简化,只在输入层中添加学习的软提示向量 (不像预写调整一样注入每个层),更换了一些表达性,以更少的可训练参数和更简单的实现.

**交易.**两种方法都是极其参数效率 (通常甚至比LoRA更高,在原始可训练参数数数中) 但与LoRA类型方法相比,它们通常在任务和模型尺度上表现得更不一致,而像适配器一样,在推理时添加一些序列计算 (额外的"代码"用于预置/即时向量进行处理) 而不是清晰融入现有权重.

## 较量表

|方法|可训练的参数 (与完全细调相比) |增加推理延迟?|备注|
|---|---|---|---|
|完全调整| 100% |没有|最高的内存/计算成本;最佳任务性能上限 |
|洛拉|通常是<1%|没有 (可合并为基权重) |标准现代默认;多个适配器可以共享一个结的基模型|
|罗拉|通常是<1% (加上量化结的基础) |没有 (适配器可合并;基模型运行量化) |最低的微调内存足迹; 允许消费者硬件微调|
|适配器|较小 (几%)|是的 (前进通行额外层) |早期,已成熟的PEFT方法|
|预写调整|非常小|是的 (需要更多的背景) |比快速调整更具表达性;比LoRA更不一致|
|快速调整|最小的|是的 (额外输入词元) |最简单;最有效的参数;更可变的性能|

## 现状

洛拉 (以及特别限制细调内存的QLoRA) 是2026年起标准的默认参数效率细调方法,因为其结合强大的实验性性能,合并时加上零推理延迟,以及与共享的冷基模型相比保持许多轻量级任务特定适配器的实际便利性.在最大任务性能证明其成本时,或在训练前的附属大规模后训练阶段,一些实验室在任何基于PEFT的定制层下游应用之前运行自己的基模型.
