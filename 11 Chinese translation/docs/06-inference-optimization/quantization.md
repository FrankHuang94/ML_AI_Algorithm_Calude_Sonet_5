# 量化

量化减少了用于表示模型的权重 (有时是激活的) 数学的精度,缩小了内存足迹,并经常以某种成本加快计算精度.本文件涵盖了为什么这特别重要于推理,低位表示的机制,对量化应用的两个主要方法和最广泛使用的两个实用方法 (GPTQ, AWQ).

## 为什么量化对推理成本重要

**基本的线路.**网络权重通常在训练期间存储和计算在16位或32位浮点格式中 (更高的精度有助于数值稳定的梯度基于优化见[optimization-algorithms.md](../01-foundations/optimization-algorithms.md)推理 (使用已经训练有素的模型来做预测) 与训练有素的数值要求不同,通常更宽容.

**为什么这在法学士级别上如此重要.**模型的内存足迹由其参数数量乘以每参数所使用的字节数量所占主导地位.存储在16位精度的70亿字节参数模型需要大约140GB仅仅用于权重,然后计算KV缓存 (见[kv-cache-and-attention-optimization.md](kv-cache-and-attention-optimization.md)直接和比例地减少了存储量需求,这对服务成本非常重要:它决定了需要多少加速器 (以及加速器的成本) 才能保持和服务给给定的模型,以及可以合集多少请求 (见[serving-and-batching.md](serving-and-batching.md)由于许多LLM推理工作负载是基于存储带宽而不是纯计算的 (从存储器移动权重到计算单位往往是瓶,而不是算法本身) 较小的权重表示可以直接转化为更快的推理,而不是仅仅是更便宜的存储.

## 机械 INT8/INT4

**核心想法.**代替表示每个权重为16或32位浮点数,将其表示为低位整数 (通常是8位或4位),以及少量的额外共享信息 (a **规模因素**有时,**零点**通过"compact integer representation"和一个实际值的数字之间,

**核心机制.**对于一个权重组 (例如,矩阵的一行中的所有权重或其他选择的组合),找到现有的值范围,并定义一个规模因子s,以:

```
quantized_value = round(real_value / s)
real_value_approx = quantized_value · s
```

设想一下,每一个连续的权重都在一个只有几梯子的梯子上,将其到最接近的""上.

```
   Original weights (continuous):   -0.9   -0.3    0.0   0.25   0.7   0.95
                                       │      │      │     │      │     │
                                       ▼      ▼      ▼     ▼      ▼     ▼
   INT4 grid (16 evenly-spaced rungs across the range, here −1 … +1):
     -1.0  -0.87 ... -0.33 -0.20  0.0  0.20  0.33 ...  0.73  0.87  1.0
       │           │      │            │     │              │
   snapped:      -0.87  -0.33   0.0   0.20  0.73  0.87   ← each weight rounds to its nearest rung
   error:        (−0.03)(+0.03) (0)  (−0.05)(+0.03)(−0.08)  ← small rounding error per weight
```

通过:s被选为使可用的整数范围内可达的真值权重的完整范围 (例如,签署的8位整数为 −128至127或4位为 −8至7).乘以s和圆形将每个权重缩小成一个小整数;乘以s将这个整数回归回来,将原始值的近似值恢复到不准确,因为圆形到最近的可达整数失去了一定精度,但足够接近,以保证模型的整体行为得到了大致的保护.它完全有效的原因是:一个大型模型的平均权重数有数十亿,个个圆形错误是小而大致独立的,因此它们往往更容易确定 整数模型的平均值,而不是一个小小的方法. 由于圆形到最近的可达整数量失去了一定精度,但足够接近,以保证模型的整体行为得到了大致的保护. 由于这个模型的运行率大致是几十亿个,而每个圆形错误的平均值都较小,所以它们往往更容易确定 整数模型的平均值,而不是总数量更小而大,但总体积更容易确定一个方法. 在一个小的方法上,在一个过程中,我们总是要确定一个更准确的方法 (                                                                                                                                                                                                                                                                                                                                                                 

## 培训后的量化 (PTQ) 与量化意识培训 (QAT)

**培训后量化 (PTQ).**根据标准,在使用一个小的校准数据集 (通过模型运行一些代表性输入来观察现实激活/权重范围,并提供了良好的规模因素选择) 后,量化已经完全训练的模型的权重,但没有进一步基于梯度的培训. 这是一种快速和便宜的应用 (不需要重新训练),并且是适应现有预训练模型的标准选择,以更便宜的推理.

**量化意识培训 (QAT).**模拟量化效果*在*训练本身 (通常是通过将权重/激活量圆到前进传递中的量化表示,同时仍然计算梯度,好像值是完全精确的,允许模型调整自己的权重来弥补在推理时将会遇到的量化噪音). 这通常在比特Q的非常低位宽度上产生更好的精度,因为模型有机会实际上调整训练过程中的精度损失,而不是仅仅在事实之后,但更昂贵.

**现状.**对于现有大型预训练模型的安装,PTQ是目前更常用的方法,正是因为它不需要重训;QAT更选择性地使用,在非常激进的量化水平上挤出最大精度的设置中,值得增加的训练成本.

## 果

**起源.**弗兰塔尔,阿什布斯,霍夫勒,阿里斯塔尔, "GPTQ:生成前训练Transformer的准确后训练量化" (2022年).

**核心贡献**GPTQ 是一种PTQ方法,它一次量化模型的权重,并对每个层的权重进行量化,使用第二级信息 (与赫西式相似的近似方法)[optimization-algorithms.md](../01-foundations/optimization-algorithms.md)) 通过调整每个权重量量化来弥补所引入的错误*未定量化*错误不仅仅是独立积累,而且在整个层中没有纠正.

**为什么这很重要.**GPTQ证明,大型语言模型可以量化到非常低的位宽度 (通常是4位,有时更低) 并且与相对较少的精度降低,并且没有任何重训,使用相对快速的,一次校准程序使得攻击性PTQ在高量级的大型预训练模型上具有实用性.

## 动作意识权重定量化

**起源.**林等人",AWQ:激活意识权重量化用于LLM压缩和加速" (2023).

**核心贡献**,与异常大的大小激活相互作用的权重对模型的输出产生巨大影响,保护了的精度.*这些*通过通过校准通过识别它们,并以比较少的攻击性量化处理,例如,在量化之前重新扩展量化, 保存了原始模型的精度, 比对每个量量均处理更高.

**为什么这很重要.**AWQ与GPTQ具有竞争性 (在一些报告比较中,比较好),同时更简单更快运行 (不需要GPTQ更具参与性,单次依赖的错误补偿过程),使其成为用于部署的大型模型量化的流行实践选择.
