# 切割和蒸

除了量化 (见 ) 之外,切割和蒸是另外两种方法.[quantization.md](quantization.md)) 使训练模型运行更便宜,直接减少其数量 (切割) 或训练一个较小的模型模仿一个更大的模型 (蒸).

## 度切割

**名称和定义**极度剪裁消除了极度值较小的权重,因为小极度权重对网络的输出贡献相对较小,并且可以以最小的对准确性的影响进行零化 (移除).

**核心机制.**训练后 (或训练期间),按绝对大小排列所有权重,并将最小的部分权重设置为完全零,通常会被进一步细调的时间接下来,让剩余的权重调整并恢复从删除的连接中丢失的一些精度. 这可以反复重复 (稍微剪切,细调,再剪切,再细调) 达到更高的稀疏度水平 (删除的权重小部分) 与更少的精度损失比在一次拍摄中剪切一切.

**为什么这很重要.**通过大小切割,在许多架构中表明,**过度参数化**对于给定的任务, 大量的权重 (在一些广泛报道的情况下,超过一半) 可以在很少或没有的准确性损失下移除,这表明训练有素的网络的原始参数数数量不完全必要于其学习功能.

## 结构化与非结构化剪裁

**无结构切割**无论它们是最小的,无论是什么更大的结构模式,都能消除单个权重. 这可以实现高稀疏性,但最小的精度损失,但结果的零权重模式是不规则的,分散的,这对现代加速器硬件 (GPU/TPU) 实际实现速度非常不适合:它们是为大型,定期,密集的矩阵乘法而构建的,标准硬件通常不能跳过单个分散的零值来节省计算时间,只有专业的稀疏计算硬件/芯片才能,即使是这样,通常只适用于特定的稀疏性模式.

**结构化剪裁**整个神经元,整个频道 (在CNN中查看[cnn-family.md](../03-deep-learning-architectures/cnn-family.md)),或全重注意力头 (在Transformer中见[transformer-architecture.md](../03-deep-learning-architectures/transformer-architecture.md)而不是单个分散的权重. 这产生了一个较小,但仍然完全密集的,定期形状的网络 (例如,一个具有较少神经元的层,而不是相同数量的神经元,一些连接被零化),在没有需要专业的稀疏计算支持的情况下,在标准硬件上实现了真正的速度升级,而这通常比无结构化的剪切更不精确 (删除整个神经元/道/头更粗,更具破坏性的变化,而不是删除单独选择的权重),因此通常会导致更高的精度损失,以减少参数.

**实际的交易.**结构化剪裁在纸上实现更高的准确性,但结构化剪裁更有可能实际上转化为现实世界上的快速化,

## 知识蒸

**名称和定义**知识蒸培训一个较小的"学生"模型,以复制一个更大的,已经训练有素的"老师"模型的行为,而不是 (或除了) 直接培训学生在原始硬标签上.

**起源.**希顿,Vinyals,院长, "神经网络中的知识分离" (2015),建立在相关的早期"模型压缩"想法 (Bucilă,Caruana,Niculescu-Mizil,2006).

**核心机制:教师与学生的框架.**蒸培训学生不仅仅是为了匹配硬,单热的正确标签,而是为了训练学生匹配老师在所有类/词元 ("软标签"或"软目标") 上的全部输出概率分布.**温度**在软max 中 (见 [autoregressive-generation.md](../04-generative-models/autoregressive-generation.md)对于温度在不同的环境中的作用 (这里它是在培训期间而不是采样时间中应用) 为了缓和教师的分布并揭示了他对所有非顶级选择的相对信心的更多信息,而不仅仅是他认为哪个单个答案是正确的.

```
Loss = α · CrossEntropy(student, true_label) + (1 − α) · CrossEntropy(student, teacher_soft_labels)
```

通过:老师的全部输出分布编码了更多信息,而不仅仅是单一的顶级预测 例如,一个分类图像的老师可能将其大部分概率归类为"狗",但也可能更为可能归类为"狼"而不是"飞机",而相对相似信息 (有时不正式称为"黑暗知识")本身是一种有用的训练信号,除了"正确的答案是狗".训练学生匹配这个更完整的分布 (混合或代替,原始的硬标签损失,加权 α) 让小学生学习更细微的近似,更大的老师学到了什么,经常产生一个比一个更小的模型更好的表现,仅仅仅是原始的硬标签上训练的相同尺寸.

**为什么这很重要.**蒸提供了将大型模型压缩到更小,更便宜的部署的一般,任务不知名的配方,而不需要模型特定的压缩技术,并且已广泛应用于一般模型压缩和特别是作为被报道称用于训练较小,更快的模型之一,以推理成本的小部分接近较大的边界模型的能力.

## 在生产模型家庭中的现实使用

截至2026年,本节所涵盖的三个家庭 (量化,剪裁和蒸) 都常用于**共同**,不作为相互排斥的替代方案,典型的生产部署管道可能将大型模型化到更小的架构,然后量化后的较小模型进一步部署,应用结构化剪裁作为一个额外的步骤,在硬件/延迟限制证明了准确性交易. 化已经成为一个特别突出的,广泛报道的技术,用于生产较小的"快速"或"迷你"的边界模型家族,旨在延迟和成本敏感的使用情况,在完全不需要全规模旗舰模型的功能.

## 强度和局限性

- **剪切**强度:可以实现高稀少性,但可少的精度损失 (特别是结构化的剪裁,如果仔细完成);减少了内存和实际计算成本 (用于结构化的剪裁).限制:不结构化的剪裁通常不会转化为没有专业支持的真正硬件速度;反复的剪裁和细调周期增加了对一击压缩方法的工程和计算总费用.
- **蒸**优势:一般用途,建筑-无意识的压缩配方;可以产生一个真正较小,更快的模型,而不是只是一个较稀少的版本的相同的建筑;结果的学生模型往往比从零开始训练的学生模型更准确,仅仅在硬标签上.限制:需要访问运行教师模型 (并且理想情况下,需要样本许多教师产品) 作为学生培训的一部分,在压缩过程中增加计算成本;学生的能力基本上由教师可以教的限制,不会自发超越一个好选择的教师自己的能力.

## 与其他算法的关系

- 切割和蒸通常与量化结合 (见[quantization.md](quantization.md)) 在生产压缩管道中.
- 蒸的软标签/温度机制与自动降低样本采样所使用的温度密切相关,但目的与其不同.[autoregressive-generation.md](../04-generative-models/autoregressive-generation.md).
- 蒸也被用作数据生成策略 (自蒸) 而不是纯粹的压缩技术.[curriculum-and-data-strategies.md](../05-training-methodology/curriculum-and-data-strategies.md).
