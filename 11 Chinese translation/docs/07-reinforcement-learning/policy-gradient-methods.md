# 政策逐步方法

政策梯度方法是第二大RL范例,除了在[value-based-methods.md](value-based-methods.md)而不是学习一个值函数并从中间接地推导出政策 (例如",选择具有最高Q值的行动"),政策梯度方法直接学习和优化政策本身.该文件从REINFORCE通过演员批判方法建立到PPO,因为PPO是经典RLHF的RL算法 (见[rlhf-and-alignment.md](../05-training-methodology/rlhf-and-alignment.md)).

## 强化

**名称和定义**强化直接对政策进行参数|根据LLM的参数 θ ,这是模型的下一个词元概率分布) 和更新 θ使用梯度上升,使得导致高奖励的行动更有可能.

**起源.**威廉姆斯"连接强化学习的简单统计学分数后续算法" (1992).

**核心机制.**

```
∇θ J(θ) = 𝔼 [ ∇θ log π(a|s; θ) · R ]
```

通过:J(θ) 是当前政策下预期的总奖励**政策梯度定理**由于衍生本身需要比本库的观众校准假设更大的概率理论[scope-and-methodology.md](../00-overview/scope-and-methodology.md)) 说:为了改善政策,将行动的记录概率提高,以比较于采取行动的总奖励R. 如果行动导致了高奖励,则增加它的概率;如果导致低 (或负) 的奖励,则减少它的概率.这是一个真正优雅的结果它允许你通过仅仅使用事件的样本 (状态,行动和随后的奖励) 来改善政策,而根本不需要一个模型来说明环境动态.

**现在,它很少被直接使用.**雷恩福斯的原材料存在严重的实际问题:其梯度估计非常高.**变化**(从任何单个样本轨迹计算的具体数值更新可能与"真实"平均更新非常不同,尽管它在许多样本中平均正确),这使得训练在实践中缓慢和不稳定. 这直接激励下面的演员-批评框架.

## 演员批判方法

**名称和定义**通过结合一个政策 (the **演员**通过学习值函数 (the **评论家**评价者的价值估计被用来判断一个行动比预期更好或更糟,而不是仅仅依赖于随后的原始,杂的总奖励.

**核心机制 (概念性).**根据 REINFORCE 的情况, 政策梯度更新的规模要由原始总奖励 R 扩大,**优势**估计A(s,a) = (实际结果) − (该状态的批评预期值基线),具体衡量该特定行动的改善或恶化程度*与预期的相比*通过:如果一个状态已经是一个伟大的在 (高预期值不论行动),即使一个适度好的行动不应该得到一个巨大的积极更新 重要的是行动是否*比批评者已经预期的更好*减去这个预期值基线显著减少梯度估计的差异 (数学上合理的技术,基线术语对梯度的预期值为完全零,因此减去它不会偏见更新,但它确实减少了噪音) 与使用原始,未调整的奖励相比.

## 子 (子) 子 (子)

**起源.**密思 (DeepMind) 的研究,即"深度强化学习的异步方法" (2016).

**核心贡献**作为一个反复播放的效益,A3C同时运行许多演员-批评代理,每个代理与其环境的独立副本相互作用,并异步向共享的参数组发送梯度更新,而不是连续运行单个代理.[value-based-methods.md](value-based-methods.md)许多平行代理人自然产生比单个代理人更多样化的,不太时间相关的经验,这稳定了培训同时也提供了更直接的方式来使用更多的计算 (许多平行员工) 来加快培训.

**现状.**尽管在大多数现代应用中,包括RLHF,A3C的核心思想 (并行演员-批评培训,基于优势的更新) 仍然具有影响力,但在实践中,它已被PPO (下面) 取代.

## 信任区域政策优化 (TRPO)

**起源.**根据"信任地区政策优化" (2015).

**解决的问题.**简单的政策梯度更新有时可以采取太大的步骤 在一个步骤中更新政策,以至于其行为会发生急剧变化,反而变得更糟,而不是更好 (不同于监督学习,*下一个*由于政策决定了所采取的行动,这可能会加剧不稳定性,而不是仅仅导致一个糟糕的训练步骤).

**核心机制 (概念性).** TRPO 限制每次政策更新都保持在"信任区域" 正式,对 KL 差异有限制 (见 [loss-functions.md](../01-foundations/loss-functions.md)) 对于新政策和旧政策的关系,使得政策的行为在任何一次更新中都不能过于发生变化,即使原始,无限制的梯度方向表明了大步.这使得培训比天真的梯度更稳定,而不是简单的梯度步骤,而是在一个更具数学和计算参与性的优化程序 (解决每次更新的限制优化问题而不是简单的梯度步骤) 的代价上.

## 接近政策优化 (PPO)

**起源.**舒尔曼等人, "近距离政策优化算法" (2017).

**动机.**不让政策在一次更新中过于发生变化,而是用更简单的机制取代TRPO的昂贵的限制优化机器,可使用普通基于梯度优化实现 (见[optimization-algorithms.md](../01-foundations/optimization-algorithms.md)),使其实现和调整变得更加容易,同时在实践中实现了相当稳定和性能.

**核心机制 切断的替代目标.**

```
r(θ) = π_new(a|s; θ) / π_old(a|s; θ)
L(θ) = 𝔼 [ min( r(θ) · A,  clip(r(θ), 1−ε, 1+ε) · A ) ]
```

通过,术语为术语:r(θ) 是新政策采取给定的行动的概率和旧政策采取相同行动的概率之间的比率 一个值接近1意味着该政策没有改变很多,一个值远离1意味着它已经改变了很多. A是优势估计 (如上述演员-批评方法) 如果行动结果比预期更好,否则更糟.**剪辑**函数限制r(θ) 保持在1周围的狭窄带内 (例如,[1−ε, 1+ε]平均值为 0. 2 左右,**时间**在外表中,取出较小的目标:未剪切的目标,或剪切的目标.

截图最容易看到的就是平板上限 (对于好行为) 或地板 (对于坏行为) 关于改变政策的更新是多少的奖励:

```
   objective                     A > 0 (good action: we want p↑)
   contribution
        │          ___________________  ← clip ceiling: no more reward for
        │         /                       pushing p beyond 1+ε in one step
        │        /
        │       /   ← reward grows as we increase p, UNTIL the ceiling
        │      /
   ─────┼─────┼──────┼──────────► r(θ) = p_new / p_old
        │   1−ε  1  1+ε
        │
        │  For A < 0 (bad action: we want p↓), the picture flips vertically:
        │  a flat FLOOR stops rewarding pushing p below 1−ε in one step.
```

为什么这个具体构建工作:当优势A是积极的 (行动是好的,所以我们想增加它的概率),那么min-of-clip-and-unclipped构建意味着一旦r(θ) 超过1+ε ,即一旦政策已经增加了该行动的概率"足够",剪缩术语将进一步提高奖励,从而消除了继续在一个更新中增加相同行动的概率的激励.当A是负面 (行动是糟糕的),对称逻辑阻止政策减少该行动的概率超过一个步骤的剪辑范围.净效果,不需要TRPO的明确差距限制机制,是"软"的想法:通过通过通过通过加快快操作,让您在一个步骤中保持了相当大的奖励,而不是通过加快速度进行加快速度.

**为什么这很重要.**基于标准梯度方法 (不需要单独的限制优化解决器),实现稳定性和简单性. 这种稳定性和简单性的结合正是PPO成为了非常广泛的应用程序中默认的RL算法选择的原因.[rlhf-and-alignment.md](../05-training-methodology/rlhf-and-alignment.md)),其中"旧政策"是模型在更新之前的行为,而"新政策"是其后的行为,优势估计是从奖励模型的分数中得出的 (根据该文件所述的KL罚款与参考SFT模型进行调整).

## 优势估计:GAE (简短)

**名称和定义**概括优势估计 (Schulman et al., 2015 同一个更广泛的研究线程如TRPO) 提供了计算上述使用的优势估计A(s,a) 的原则性方法,平衡使用纯即时奖励信号 (低偏差,高变化) 和更严重依赖评论家自己的价值预测在未来 (如果评论家的估计不完美,但变化较低) 之间进行交易.
