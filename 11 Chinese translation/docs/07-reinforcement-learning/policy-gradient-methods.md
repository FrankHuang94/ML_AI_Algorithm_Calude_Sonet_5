# 策略梯度方法

策略梯度方法是 RL 的第二大范式，与 [value-based-methods.md](value-based-methods.md) 中介绍的基于价值的方法并列——它不是先学习一个价值函数、再从中间接推导出策略（例如"选 Q 值最高的那个动作"），而是直接学习并优化策略本身。本文件从 REINFORCE 出发，经过演员-评论家（actor-critic）方法，一路讲到 PPO；由于 PPO 是经典 RLHF 背后的 RL 算法（见 [rlhf-and-alignment.md](../05-training-methodology/rlhf-and-alignment.md)），这里会对它讲得更深入一些。

## REINFORCE

**名称与定义。** REINFORCE 直接对策略 π(a|s; θ) 进行参数化（即在给定参数 θ 时、在状态 s 下采取动作 a 的概率——对 LLM 而言，这恰好就是模型的下一词元概率分布），并用梯度上升更新 θ，方向是让那些带来高奖励的动作更可能被选中。

**起源。** Williams，"Simple Statistical Gradient-Following Algorithms for Connectionist Reinforcement Learning"（1992）。

**核心机制。**

```
∇θ J(θ) = 𝔼 [ ∇θ log π(a|s; θ) · R ]
```

解读：J(θ) 是当前策略下的期望总奖励——也就是我们真正想要最大化的量。这个公式（**策略梯度定理**；本文件只陈述、不完整推导，因为推导本身需要的概率论超出了本仓库读者定位的假设——见 [scope-and-methodology.md](../00-overview/scope-and-methodology.md)）说的是：要改进策略，就按照采取某个动作之后获得的总奖励 R 的大小，成比例地提高该动作的对数概率。如果一个动作带来了高奖励，就提高它的概率；如果带来了低（或负）奖励，就降低它的概率。这是一个相当优雅的结果——它让你只凭"发生了什么"的样本（状态、动作以及随后的奖励）就能改进策略，完全不需要环境动态的模型。

**为什么如今很少被直接使用。** REINFORCE 的原始形式有一个严重的实际问题：它的梯度估计**方差（variance）**非常高（从任意单条采样轨迹算出的具体数值更新，可能与"真实"的平均更新相差甚远，尽管在大量样本上平均来看是正确的），这让训练在实践中又慢又不稳定。这直接催生了下面的演员-评论家框架。

## 演员-评论家方法

**名称与定义。** 演员-评论家方法通过把一个策略（**演员（actor）**，决定采取什么动作）与一个学习得到的价值函数（**评论家（critic）**，估计某个状态或动作有多好）结合起来，降低策略梯度的方差——评论家的价值估计被用来判断一个动作的结果比预期好了多少或差了多少，而不是单纯依赖随后那个原始的、充满噪声的总奖励。

**核心机制（概念层面）。** 不再像 REINFORCE 那样用原始总奖励 R 去缩放策略梯度更新，而是用一个**优势（advantage）**估计 A(s, a) =（实际结果）−（评论家对该状态的期望价值基线）去缩放，它专门衡量这个特定动作的表现*相对于在该状态下本已预期的水平*好了多少或差了多少，而不是它的绝对奖励。解读：如果某个状态本身就很好（无论采取什么动作期望价值都很高），那么即使一个还算不错的动作，也不该得到巨大的正向更新——重要的是这个动作是否*比评论家原本的预期更好*，而不是孤立地看它的原始奖励。减去这个期望价值基线，会显著降低梯度估计的方差（这是一个有数学依据的技巧——基线项对梯度贡献的期望值恰好为零，因此减去它不会使更新产生偏差，但确实会降低噪声），这是相对于使用未经调整的原始奖励而言的。

## A3C（异步优势演员-评论家）

**起源。** Mnih 等（DeepMind），"Asynchronous Methods for Deep Reinforcement Learning"（2016）。

**核心贡献。** A3C 并行运行许多演员-评论家智能体，每个智能体与自己独立的环境副本交互，并异步地把梯度更新发送到一组共享参数上，而不是顺序运行单个智能体。这起到的作用在某种程度上类似于 DQN 中经验回放带来的去相关效果（见 [value-based-methods.md](value-based-methods.md)）——许多并行智能体自然会产生比单个智能体更多样、时间相关性更弱的经验，从而稳定训练——同时它也提供了一种直接利用更多计算（许多并行工作进程）来加速训练的方式。

**现状。** A3C 的核心思想（并行的演员-评论家训练、基于优势的更新）依然有影响力，不过在包括 RLHF 在内的大多数现代应用中，它在实践上已基本被 PPO（见下文）取代。它的影响力得到了正式认可：A3C 论文（Mnih 等，2016）获得了 **ICML 2026 时间检验奖（Test of Time award）**（ICML 2026，首尔，2026 年 7 月）——该奖项授予大约十年前发表、影响力经久不衰的论文。

## 信赖域策略优化（TRPO）

**起源。** Schulman 等，"Trust Region Policy Optimization"（2015）。

**它要解决的问题。** 朴素的策略梯度更新有时会迈出过大的一步——在一步之内把策略改得太多，导致其行为剧烈变化，并且适得其反地变得更差而非更好（与监督学习不同，RL 中一次糟糕的策略更新会直接、立即影响你*接下来*收集到什么数据，因为策略决定了所采取的动作，这可能让不稳定性层层累积，而不仅仅是造成一个糟糕的训练步）。

**核心机制（概念层面）。** TRPO 约束每次策略更新都停留在一个"信赖域"之内——形式上，就是对新旧策略之间的 KL 散度（见 [loss-functions.md](../01-foundations/loss-functions.md)）设一个上界——这样即使原始的、不受约束的梯度方向建议迈一大步，策略的行为在任何一次更新中也不会变化得太剧烈。这让训练比朴素策略梯度稳定得多，代价是优化过程在数学和计算上都更复杂（每次更新都要求解一个带约束的优化问题，而不是简单地走一步梯度）。

## 近端策略优化（PPO）

**起源。** Schulman 等，"Proximal Policy Optimization Algorithms"（2017）。

**动机。** PPO 保留了 TRPO 的核心目标——不让策略在单次更新中变化太剧烈——但用一种简单得多的机制取代了 TRPO 昂贵的约束优化机制，这种机制可以用普通的基于梯度的优化实现（见 [optimization-algorithms.md](../01-foundations/optimization-algorithms.md)），从而在实践中以大体相当的稳定性和性能，大大降低了实现和调参的难度。

**核心机制——裁剪代理目标（clipped surrogate objective）。**

```
r(θ) = π_new(a|s; θ) / π_old(a|s; θ)
L(θ) = 𝔼 [ min( r(θ) · A,  clip(r(θ), 1−ε, 1+ε) · A ) ]
```

逐项解读：r(θ) 是新策略采取某个动作的概率与旧策略采取同一动作的概率之比——接近 1 表示策略在这个动作上变化不大，远离 1 表示变化很大。A 是优势估计（与上面的演员-评论家方法相同）——动作结果好于预期时为正，差于预期时为负。**clip** 函数把 r(θ) 限制在 1 附近的一个窄带内（例如 [1−ε, 1+ε]，ε 常取 0.2 左右），外层的 **min** 则在未裁剪的目标与裁剪后的目标中取较小者。

把裁剪理解成"一次更新因改变策略而获得的奖励"上的一块平顶（针对好动作）或平底（针对坏动作），是最直观的：

```
   目标函数                       A > 0（好动作：希望 p↑）
   贡献
        │          ___________________  ← 裁剪上限：一步之内把 p 推过 1+ε
        │         /                       不再获得更多奖励
        │        /
        │       /   ← 随着 p 增大，奖励增长，直到碰到上限
        │      /
   ─────┼─────┼──────┼──────────► r(θ) = p_new / p_old
        │   1−ε  1  1+ε
        │
        │  当 A < 0（坏动作：希望 p↓）时，图形上下翻转：
        │  一块平坦的"地板"使一步之内把 p 压到 1−ε 以下不再获得奖励。
```

为什么这种特定构造有效：当优势 A 为正（动作是好的，所以我们想提高它的概率）时，"裁剪与未裁剪取最小"的构造意味着，一旦 r(θ) 超过 1+ε——也就是策略已经把这个动作的概率提高得"足够多"了——裁剪项就会封顶，继续把 r(θ) 推高不再带来更多奖励，从而消除了在一次更新中无限提高同一动作概率的动机。当 A 为负（动作是坏的）时，对称的逻辑会阻止策略在一步之内把该动作的概率降得超过裁剪范围所允许的程度。净效果是：无需 TRPO 那套显式的 KL 散度约束机制，就实现了同一核心思想的"软"版本——不要让一个训练步过于剧烈地改变策略在任何给定动作上的行为，因为一旦移动得足够远，这样做的奖励就被封顶了。需要记住的直觉是：PPO 说的是"要改进，但要迈小而可信的步子"——它是 RL 版的小学习率，只不过不是直接限制步长，而是通过给过于急切的移动的奖励封顶来实现。

**为什么重要。** PPO 达到了与 TRPO 大致相当的稳定性，而它的目标函数简单到可以用标准的基于梯度的方法优化（不需要单独的约束优化求解器），这使它在实现、调参和扩展上都容易得多——稳定性与简单性的这种结合，正是 PPO 成为众多应用中默认 RL 算法的原因，其中当然也包括经典 RLHF 的 RL 阶段（见 [rlhf-and-alignment.md](../05-training-methodology/rlhf-and-alignment.md)）：在那里，"旧策略"是模型更新前的行为，"新策略"是更新后的行为，而优势估计来自奖励模型的分数（并按该文件所述，用针对参考 SFT 模型的 KL 惩罚进行调整）。

## 优势估计：GAE（简述）

**名称与定义。** 广义优势估计（Generalized Advantage Estimation，Schulman 等，2015——与 TRPO 属于同一研究脉络）提供了一种有原则的方式来计算上文使用的优势估计 A(s, a)。它在两者之间权衡：纯粹使用即时奖励信号（低偏差、高方差），与更多地依赖评论家对更远未来的价值预测（若评论家估计不完美则偏差更高，但方差更低）——用一个可调参数（λ，lambda）在这两个极端之间平滑插值。在大多数实际实现中，GAE 都是与 PPO 搭配使用的标准组件，典型的 RLHF 流水线也不例外。

## PPO 在 LLM 时代的后代：GRPO、DAPO 的 clip-higher 与 GSPO（简述）

PPO 的裁剪比率在 LLM 时代并没有消失——它被继承并加以修改。完整的来龙去脉（含公式与直觉）见 [rl-for-llms.md](rl-for-llms.md)；这里说明每个后代与上面的 PPO 目标是什么关系。

- **GRPO（DeepSeekMath，2024；DeepSeek-R1，2025）** 完全保留了 PPO 逐词元的 `min(r·A, clip(r, 1−ε, 1+ε)·A)`，但用*组基线*取代了"评论家 + GAE"式的优势：对同一个提示采样若干条回复，用每条回复的奖励减去组内均值（最初还要再除以组内标准差）。根本不训练价值模型——本文件前面的演员-评论家思想得以保留，只不过"评论家"现在只是一个平均数。
- **DAPO 的"clip-higher"（2025）** 把 PPO 的裁剪带变得不对称：`clip(r, 1−ε_low, 1+ε_high)`，其中 ε_high > ε_low。用上面平顶/平底的图来说，只有好动作的*上限*被抬高了。原因在于，上限限制的是*相对于*当前概率的增长：取 ε = 0.2 时，概率为 0.01 的词元一次更新最多只能升到约 0.012，而概率为 0.9 的词元实际上不受约束。因此，对称的裁剪带会让稀有但有益的词元始终保持稀有，策略的随机性（熵）随之坍缩，探索也就停止了。只抬高上限，就能让这些词元成长，而下限依然能防止过于急切的压制。
- **GSPO（Qwen 团队，2025）** 把比率从词元层面移到*序列*层面：r 变成整条回复的概率比，并以几何平均的方式做长度归一化，即 `(π_new(o|q) / π_old(o|q))^(1/|o|)`，每条回复只裁剪一次。动机是：奖励是按序列给出的，因此逐词元比率只是带噪声的单样本估计，其噪声会在数千个词元上累积——而在混合专家（MoE）模型中，新旧策略之间的路由变化会让噪声更大。在奖励真正所在的层面上做裁剪，会更稳定。

共同的主线是：它们仍然都是"要改进，但要迈小而可信的步子"——争论只在于该信任*哪一种*步子（逐词元还是逐序列），以及信赖域应该有多对称。

## 比较表

| 方法 | 年份 | 关键创新 | 是否仍然重要（2026 年末）？ |
|---|---|---|---|
| REINFORCE | 1992 | 通过对数概率加权直接计算策略梯度 | 奠基性理论；高方差限制了直接使用 |
| 演员-评论家（通用） | — | 基于评论家的优势降低梯度方差 | 奠基性框架，贯穿各种现代方法 |
| A3C | 2016 | 并行异步的演员-评论家训练 | 有影响力（ICML 2026 时间检验奖）；实践中基本被 PPO 取代 |
| TRPO | 2015 | 用显式 KL 信赖域约束实现稳定更新 | 奠基性；基本被 PPO 更简单的机制取代 |
| PPO | 2017 | 裁剪代理目标——用简单梯度步实现类似 TRPO 的稳定性 | 是——仍是默认的通用 RL 算法，也是 LLM RL 的参照基准 |
| GRPO 系列（GRPO、DAPO、Dr. GRPO、GSPO） | 2024-2025 | 用组均值基线代替评论家的 PPO 式裁剪；改进的裁剪/归一化 | 是——LLM 上可验证奖励 RL 最常用的选择 |

## 与其他算法的关系

- PPO 是经典 RLHF 策略优化阶段背后的 RL 算法——它所处的完整流水线见 [rlhf-and-alignment.md](../05-training-methodology/rlhf-and-alignment.md)。
- TRPO 中的 KL 散度约束（以及 PPO 对同一思想的更柔和版本）使用的是 [loss-functions.md](../01-foundations/loss-functions.md) 中介绍的同一个数学对象，它在 RLHF 中又以漂移惩罚的形式再次出现。
- [rl-for-llms.md](rl-for-llms.md) 是把这些通用 RL 理论专门连接到 LLM 训练实践的桥梁文件，其中包括上文概述的 PPO 后代 GRPO/DAPO/Dr. GRPO/GSPO。
- 与 [value-based-methods.md](value-based-methods.md) 中的基于价值的方法形成对比——策略梯度方法直接学习策略，而不是从学习得到的价值函数中推导出策略。
