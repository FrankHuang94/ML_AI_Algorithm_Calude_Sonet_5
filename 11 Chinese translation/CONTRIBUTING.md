# 贡献

该仓库是 ML/AI 算法的参考知识库。如果要扩展它：

1. **遵循 `docs/00-overview/scope-and-methodology.md` 中的每种算法模板**（起源、机制、重要性、当前状态、优势/限制、用法、关系、来源）。
2. **更新术语表。** 引入的任何新术语都应添加到 `docs/00-overview/glossary.md` 中，按字母顺序排列，并带有一行定义和一个返回到深入涵盖该术语的文件的链接。
3. **引用来源。** 将声明归属于论文（注明年份）或将其标记为“广泛报道”。避免发明无法获取的精确基准数字——而是使用定性比较或范围。
4. **区分事实与预测。** 在路线图/展望内容中，将推测性主张标记为 `[Projection]`，并将其与来源主张明显分开。
5. **每个文件至少添加一个视觉效果** - 美人鱼图或大量比较表 - 使用 GitHub 风格的 Markdown 原生渲染。
6. **交叉链接。** 指向仓库中其他位置的相关/竞争条目，而不是重复解释。
7. **使术语与仓库的其余部分保持一致** - 在引入现有概念的同义词之前检查术语表。
